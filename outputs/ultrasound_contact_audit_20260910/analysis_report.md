# 前臂扫描的超声接触与力矩修正分析

分析日期 2026-09-10。输入为 `/media/camp/PEI_T7/icra 2027/uncalibrated` 的 68 个 H5，共 12,588 帧超声。仅作离线读取、特征提取和控制律对照，没有连接机器人或修改采集数据、补偿参数与控制器。

本批数据更支持“力矩驱动很小或落入阈值范围时，声学窗口仍可能缺失”，而不是普遍发生了很大的执行延迟。实际转动与现有力矩导纳的离线预测在多个 C/S 扫描中高度一致。与此同时，一部分黑带出现在持续转动过程中，说明仅判断是否在修正仍不足以判断成像是否改善。当前数据不能唯一判定补偿零漂，也不能证明某个理想姿态一定同时满足零力矩与完整声学接触。

这里不能把 TCP 统一称为原始 196 Hz。计算实际角速度使用原始时间差和旋转矩阵的相邻 body 增量，不使用 Euler y 的直接差分。角速度绘图及稳健速度统计采用 5 点中值滤波；原始角速度同时保存在 NPZ。该离线对称滤波没有作为实时控制器。

以超声时间戳为绘图时钟，TCP 时间增加 0.1519636505 s，力时间增加 0.1512859034 s。等价地，一帧收到的超声对应约 152 ms 前的 TCP 和约 151 ms 前的力。每张图的零点是该原始 H5 第一帧超声时间。边界没有重叠的帧不参与全量比例统计，事件表另列对齐覆盖率。

延迟来自此前体模正弦拟合，是有效相位差，并非证明过的纯采集硬件延迟。对 US 延迟做 ±20 ms 敏感性检查，53 个候选事件中 My 低于阈值占比的最大变化为 3.75 个百分点。该检查支持主要秒级现象的稳健性，不提供毫秒级因果精度。

## 无需训练的候选检测

这次实现的是可复核的灰度暗带筛查，没有训练权重，也没有把简单暗像素占比冒充 Karamalis confidence map。

有效横向区域去掉左右各约 4%，缩放为 192×224 后划分 32 个横向条带。分别计算近场约 4–22% 深度、中场约 22–45% 深度、深部约 45–80% 深度的暗像素比例。灰度阈值为 40。候选要求同一个条带的近场和中场暗像素比例均至少 75%，连续暗条带宽度至少占有效孔径 12.5%，持续至少 0.2 s，合并不超过 0.1 s 的间断。深部单独变黑不会触发。

这是为了抓取“一侧从浅层开始形成纵向黑带”的可疑区域。骨后声影、各向异性、切面改变、增益变化、近场伪影仍会造成混淆。检测时刻表示特征越过本次阈值的时刻，不是探头第一次物理抬离的精确时刻。原始裁剪已去掉接触前后的大段数据，文件开头或末尾事件需要视为截断观察。

## 修正慢、死区与零偏分别能判断到哪里

代码审计确认，当前自动修正使用补偿到 TCP 的 My，输出 tool ωy。路径在该轴的前馈及位置反馈已经被 TFF 屏蔽，所以没有发现“原姿态位置环一直把同一轴拉回去”的结构。正常接触时原法向力输出与 ωy 直接组合，没有专门的旋转—法向载荷耦合补偿。

68 个文件记录的参数一致：虚拟惯量 0.051、阻尼 0.22、Coulomb 0.025 Nm、速度上限 0.28 rad/s、加速度上限 3 rad/s²。近似滑动态时间常数 M/D=0.232 s。恒定 My 为 0.030 Nm 时，稳态速度仅约 1.3°/s；0.050 Nm 时约 6.5°/s。若 My 只略超过阈值，即使硬件完全按命令执行，修正也不会很快。

4 N 下，0.025 Nm 等价于理想 TCP 接触平面上约 6.25 mm 的压力中心横向偏移。这个死区对抑制噪声有用，但并不意味着剩余声学误差很小。直接把死区整体缩小可能同时放大噪声、残余矩和不期望的姿态变化，本批证据还不足以决定一个新的全局参数。

离线回放没有拟合新控制参数，而是直接用上述实际公式，从记录 My 计算假定接管门控一直开放时的角速度。初始速度分别设为 0 和 ±0.28 rad/s，并舍弃最初 1.2 s 比较实际角速度。重点结果如下：

| 扫描 | 预测与实际角速度相关系数 |
| --- | ---: |
| chenwei RH C DtP | 0.986 |
| chenwei RH C PtD | 0.924 |
| chenwei RH S PtD | 0.976 |
| dianye RH S PtD | 0.974 |
| zhongyao RH C DtP | 0.972 |
| zhongyao RH S PtD | 0.978 |

这些相关性在不额外平移实际角速度时已经很高。达到预设激励门槛的记录中，最佳波形平移通常约 30 ms，但提升有限，且仅为发布、执行、滤波等共同造成的表观滞后，不是新的硬件延迟标定。弱激励 L 回程不估计该 lag。总体更支持“当前导纳确实按较小的 My 生成较小动作”，没有支持普遍存在额外几百毫秒的大延迟。黑带与动作形状一致也不等于动作改善了所需声窗。

不能唯一判定零漂的原因是：文件中缺少接触前后同姿态空载基线，且接触中的 My 同时包含压力偏心、切向力杠杆效应、线缆和动态补偿残差。chenwei 与 zhongyao 的补偿模型文件快照相同；这削弱了“只因为使用了不同模型文件”的解释，但 H5 没有记录运行时加载 revision，不能进一步作过度推断。

此外，Mx 并没有自动接管。chenwei RH L PtD 的 Mx 中位数约 0.069 Nm，dianye LH L PtD 约 0.071 Nm。未释放的另一个倾斜方向、切向力和接触几何都值得保留为解释，不能看到 My 接近零就称整个接触面已经力矩平衡。H5 也没有声学图像横轴到 TCP 的安装外参，图像左黑不能直接换算成固定正负 tool ωy。

法向力还存在方向相关差别：chenwei、dianye、zhongyao 右手三类路径的去程中位 Fz 分别约 4.24、4.32、4.29 N，回程约 3.73、3.68、3.70 N。这种差别在好例和差例中都存在，不能单独解释失耦；也说明应量化基线误差，而不是直接假定每段力都精确等于 4 N。

H5 没有保存实测命令 ωy、接管门控、QP slack、冻结原因、实际加载模型版本。本批找不到覆盖扫描时间的控制器 CSV。因此不能完全区分命令产生、执行追踪和特殊门控，更不能把 My 的接触残差直接重新标为零。

## 文献对应关系

Jiang 等的 *Automatic Normal Positioning of Robotic Ultrasound Probe Based Only on Confidence Map Optimization and Force Measurement* 是 RA-L 2020、并在 ICRA 2020 展示的相关工作。其面内法向来自 confidence 图像特征，面外法向通过 fan motion 和由关节力矩估计的外力变化得到。它不是把 TCP My 直接归零的面内导纳；论文也讨论了估计力受构型和摩擦影响。[作者机构记录](https://portal.fis.tum.de/en/publications/automatic-normal-positioning-of-robotic-ultrasound-probe-based-on/)

Welleweerd 等 ICRA 2020 的 *Automated Robotic Breast Ultrasound Acquisition Using Ultrasound Feedback* 使用 confidence 修正面内角度和法向位置，并接入 SAIP 与 energy tank；该实验当时没有集成力传感器，力和超声联合调整是其讨论的后续方向。故“超声反馈加 tank”本身已有先例。[一手全文](https://ris.utwente.nl/ws/files/247785100/Welleweerd2020automatic.pdf)

Chatelain 等 T-RO 2017 已经把 confidence、力和位置任务结合；无训练的声窗控制不是新假设。Karamalis 等的 random-walk confidence map 则描述声传播可靠度，不等于接触压力或诊断价值。[T-RO 机构记录](https://portal.fis.tum.de/en/publications/confidence-driven-control-of-an-ultrasound-probe/)、[Karamalis 原论文记录](https://pubmed.ncbi.nlm.nih.gov/22906822/)

Mazdarani 与 Rossa 的 2026 作者稿将接触特征限定在皮肤附近，以降低骨等深部反射体的干扰。这支持本次先看浅层和分区窗口的方向，但不能把任何浅层暗像素阈值宣布为已验证的物理接触检测器。[作者稿](https://www.biomechatronics.ca/publications/publies/Hoorieh2026a.pdf)

Piedra 的 *Explicit force-based control strategies for compliant robot-assisted ultrasound imaging* 是 2026 年的另一篇工作，其公开摘要明确采用接触力和力矩控制。不要与同作者的 *Visuotactile and Explicitly Force-Controlled…* 混为一个版本；后者公开稿中的纯姿态运动控制不能用来否定前者。附文列出的具体旋转投影矩阵尚未在本次获取的最终全文中独立核实，不把该矩阵作为本报告设计的必要依据。[出版社](https://doi.org/10.1177/02783649261441635)、[作者实验室分别列出的两篇论文](https://khatib.stanford.edu/publications.html)

## 能估计的接触量

六轴传感器只能给合力和合力矩。对法向压力场 p，在已知平面和符号约定下：

\[
F=\int p\,dA,\qquad M_x=\int yp\,dA,\qquad M_y=-\int xp\,dA.
\]

它们只给压力的低阶矩。均匀分布、中心窄区接触和两个对称接触区可以有相同 F 与 M，却有完全不同的有效声窗。因此不能由当前数据唯一恢复二维压力分布，也不能从一幅二维 B-mode 恢复整个探头面的三维接触形状。

若合力作用平面为 tool z=z_c，可计算条件性的压力中心：

\[
x_p=(z_cF_x-M_y)/F_z,\qquad y_p=(M_x+z_cF_y)/F_z.
\]

只有 z_c=0 等条件成立时才退化为代码中的 −My/Fz 和 Mx/Fz。压力中心不等于增量刚度中心；也不等于超声置信质心。不要令 c_p=−My/Fz 后把 My+c_pFz 用作纠偏反馈，因为它会恒等消掉原来需要的力矩信号。

有用的融合输出是：可信声窗的位置和宽度、各区不足量、条件性的偏载范围、允许动作的改善方向及其可信度。有限接触面模型可以辅助约束旋转与法向力的耦合，但不能把足底等模型的全部参数直接当作人体参数。部分接触文献本身也指出，瞬时 CoP 不足以测得接触面积。[Sygulla 与 Rixen 原文](https://journals.sagepub.com/doi/pdf/10.1177/1729881419897472)

“前臂小半径所以一定有完整贴合解”也需要条件：在探头有限宽度、当前切面、路径许可及载荷上限下，整个孔径全部耦合不一定可达。应定义任务需要的声窗，再判断是否可修复，而不是为达到全图明亮继续旋转或增加力。

## 推荐的超声与力融合模块

保留现在的法向力生成器和 My 导纳作为强名义行为，保留其死区。图像只在所需声窗存在可信不足时请求补充动作。零力矩是名义偏好；不能同时把零力矩写成不可违反的硬等式，否则正好锁死本批已经观察到的盲区。

第一层每帧计算训练自由的近场分区特征。当前灰度暗带用于审查基线；控制模块可用已发表 random-walk confidence 的实现，在固定增益和固定物理深度区域中提取左、中、右窗口质量 Q_j。排除顶部固定边界和文字，区分浅层失耦候选与深部声影。质量达标后不继续奖励增亮，定义 e_j=[Q_{j,min}−Q_j]_+。窗口权重来自扫描任务，不能由优化器删除难以成像的区域来提高分数。

第二层保存约 1–2 s 的历史队列，记录图像时刻、TCP 位姿、已执行 twist、wrench、路径进度、图像特征和有效性。实时收到图像后，应到历史中关联约 152 ms 前的 TCP；当前能量与硬力限制仍使用最新高频测量，不能为了图像对齐把力反馈整体延迟 152 ms。

历史信息有三项用途：检查暗带是否持续；检查刚刚执行的转动是否改善同一个局部声窗；在接近已知问题区域时提前减速。比较时需要限制空间和姿态变化，不能把扫描进入不同组织引起的变亮当作该旋转的效果。同一路径反向时还要考虑摩擦与组织变形，不能直接照搬角度序列。

修正方向优先使用经过安装标定的图像轴和标准视觉伺服关系；局部有限差分或小窗口加权最小二乘只用于更新和核验动作—特征响应，不训练分割网络，也不把未知组织模型当成先验真值。激励不足、组织变化大、旧图像过时或响应符号反复时，降低响应可信度，保持基线或减速，不凭单帧亮度决定一个大角度。

第三层把声学请求与基线动作放入同一个笛卡尔 QP。第一版自由变量可取 ν=[v_n,ω_I] 和扫描速度比例 α；只有路径许可时才加入很小的横向修正 v_x。另一个倾斜轴由任务明确授权，不因 Mx 非零就自动释放。既有 QPIK 继续执行最终 twist，但必须提供执行偏差和 slack。

每拍固定局部参数后，定义：

\[
V=S\nu+\alpha b(s)+V_{\rm view},\qquad
\widehat Q_j^+=Q_j+h_I\ell_j^TV,
\]

\[
\min\quad \tfrac12\|\nu-\nu_b\|_R^2+w_c\zeta_F^2
+\sum_j\gamma_jw_j\xi_j^2+w_\alpha(1-\alpha)^2,
\]

\[
\xi_j\ge Q_{j,min}-\widehat Q_j^+,\quad \xi_j\ge0,\qquad
|a_{F,r}^T(V-V_b)|\le\zeta_F\quad\forall r.
\]

这里 a_F 的范围约束额外转动对法向载荷的影响，γ_j 是声学证据和局部响应的可信度，h_I 是图像预测时域，不应机械地用约 5 ms 的高速 QP 周期来要求每拍看到明显图像变化。过时图像要先结合历史位姿判断可用范围；响应预测只负责性能，不承担硬安全证明。

同时加入：角度许可、速度及加速度界、实际可执行范围、力上限和能量约束。可信失耦直接降低 α 的上界；不能只等 tank 不够才减速，因为坏接触时沿路径推进可能几乎没有端口功率。α=0 只停止路径推进，仍允许原力控与许可的修复动作。路径参数按实际接受的进度更新，避免墙钟轨迹继续前进积累追赶误差。

正常图像达标时，图像不足代价为零，额外力扰动在基线处为零；基线可行时恢复原输出。图像明确不足时允许有限偏离零力矩，但法向力仍跟踪原 F_d。只有局部证据显示加载确有收益且其他约束允许，才缓慢改变 F_d，且验证无收益就停止增加。不能采用“黑了就加力”。

这是一套基于已发表视觉伺服、导纳和约束优化方法的项目设计建议。本次没有把该融合 QP 实装到机器人，也没有以离线数据证明其闭环性能。

## 面内转动的法向耦合与能量

在约定正速度为压入的局部模型中，可写：

\[
\dot F\approx k_0(v_z-c_k\omega_I)+d_F.
\]

所以保载修复需要联合选择 v_z 与 ω_I。直接绕 TCP 转动并非独立于法向力；取 v_z=v_F+\hat c_kω_I 只是有误差的近似补偿，且 c_k 不能无条件替换为 −My/Fz。未知范围过宽时，鲁棒 QP 必然限制转动，不能同时承诺任意未知接触参数下的精确解耦和快速大角度修复。

无论是否近似恒力，都必须核算完整机械端口。在同一个点、同一坐标系定义环境作用于探头的真实 wrench W_e 和实际 twist V_a：

\[
P=W_e^TV_a=F_e^Tv_a+M_e^T\omega_a.
\]

恒定 Fz 或零法向速度都不意味着总功率为零。若采用变换 v_z=v_F+cω_I，其对偶力矩必须一起变换为 M_y+cF_z，才能保持功率不变。控制反馈的任务力矩和功率计算的对偶量各有作用，不要混为重新标定的零点。

## 普通 QP 下可以成立的无源性证明

建议先使用最终物理端口的直接能量预算，不同时再混入另一套 H_virtual+E 的账本。Benzi–Secchi 的工作支持通过能量约束选择最终名义速度，但实际速度执行、测量和延迟误差仍需单独处理。[原文](https://arxiv.org/html/2103.03082v1)

取 S_k=E_k−E_min≥0。若能对整个执行区间构造真实输入功的下界

\[
\underline{\mathcal W}_k(V)\le
\int_{t_k}^{t_{k+1}}W_e(t)^TV_a(t)\,dt,
\]

QP 约束

\[
\underline{\mathcal W}_k(V)\ge-\beta S_k,\qquad0\le\beta\le1.
\]

更新先取 \(\widetilde S_{k+1}=S_k+\underline{\mathcal W}_k\)，再在上限处仅泄放，\(S_{k+1}=\min(S_{max},\widetilde S_{k+1})\)。于是

\[
S_{k+1}\ge(1-\beta)S_k\ge0,\qquad
S_{k+1}-S_k\le\int W_e^TV_a\,dt.
\]

累加即可得到端口无源性不等式。该证明的关键条件是真实一拍功下界和能量下界都成立，而不是给程序变量取名 energy_tank。预算耗尽时不能无条件重置；人为补充预算必须作为外部供能记录。

例如使用分量误差界 |δW_i|≤wbar_i、|δV_i|≤vbar_i，可采用：

\[
\underline P(V)=W_m^TV-
\sum_i\bigl(|W_{m,i}|\bar v_i+\bar w_i|V_i|+\bar w_i\bar v_i\bigr).
\]

若这些界覆盖整个保持与执行区间，则 h·underline P 可作输入功下界。引入 t_i≥V_i、t_i≥−V_i，功率约束可保守写成线性形式，配合二次目标仍为普通 QP。测量界应包含零偏、滤波和延迟内的变化，速度界应包含 QPIK 松弛、通信延迟、加速度限制与实际跟踪误差。离线 ±20 ms 敏感性或数据分位数不是这些硬界的证明。

如果要证明接触调节的耗散，可以另构造有效的非负耗散预算，并在上述输入功下界中扣除；不能仅在目标函数中加一个速度平方，就声称实际振荡一定衰减。冻结扫描和主动参考后，还需要环境被动、储能与信号有界及适当连续性，才能从耗散推导速度趋零。无源性本身不保证正确图像、力不越界或任务总可行。

硬力限制需要独立处理。若真实力变化属于已验证的范围 \(\dot F=a_F^TV+d_F\)，对所有范围顶点约束危险增长，并覆盖整个执行周期及停止余量。没有这种界时可以做经验保护，不能写成无条件硬上限证明。数字系统仅检查采样端点通常不足以排除间隔中的越界。[采样系统 CBF 一手论文](https://arxiv.org/abs/2103.03677)

当前记录配置中 TDPA 的 apply=false，safety shield 为 observe，force barrier 未应用，且 energy_sign_verified=false。因此本批不能作为现有控制器已经完整无源的证据。下一步应先补全最终命令、实际执行、门控和功率符号日志，再在体模上验证执行误差与能量界；本次没有擅自打开这些功能。

## 实验与日志的最小增量

为了区分弱驱动、零偏和声学最优姿态，最有价值的增量是同一局部位置的受约束对照，而不是再收一批只有最终图像的完整扫描。记录初始基线、停止路径推进后原力矩控制是否自行恢复、许可的小角度动作对同一声窗的影响，以及扫描前后空载同姿态的残余 wrench。声学最佳状态对应非零力矩，应作为实验结果保存，不能在接触中把它在线归零抹掉。

日志至少增加：实际加载补偿 revision、补偿前后 wrench、倾转命令与实际 ω、Coulomb 状态、contact/tilt engaged、冻结原因、QP slack、最终接受 twist、路径实际进度、每帧采集与收到时间、分区质量和可信度、tank 能量及一拍功界。记录这些量不要求先更换当前控制器。

后续对比需要匹配扫描速度、载荷、路径和角度许可，分别比较原基线、图像补充、联合保载修复和能量约束介入情况。评价持续缺失时间、所需窗口覆盖、Fz 误差与峰值、姿态偏离、恢复时间和真实端口能量，避免把单纯减慢扫描或提高压力带来的改善都归功于融合方法。
