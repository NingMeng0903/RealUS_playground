# Torso atlas and observation model

## Geometry assets

The local Among_US anatomy retarget configuration includes skeletal, cardiovascular, respiratory and digestive collections. It maps the sternum and heart anchors to the upper spine. A readable retargeted reference snapshot contains the skin topology and named surface meshes for **Heart, Liver, Gallbladder, Sternum and 24 individual ribs**. The snapshot includes per-mesh vertex ranges and source, pre-correction and candidate coordinates. This is a usable naming and geometry source for a synthetic torso scenario. Neither this snapshot nor the lower-limb retarget audit supplies validated patient-specific rib-to-organ registration, beating chamber trajectories, calibrated ultrasound attenuation or a clinical scan.

The chest and upper abdomen can use one or more contact patches of the full reference skin mesh. Preserve template triangle indices, topology and barycentric attachments. Limit search to patches such as parasternal, apical and right subcostal while retaining the full body mesh for transport and collision checks. Each patch can use two harmonic surface coordinates anchored to anatomical directions and a depth field interpolating between local skin and a specified inner boundary. Use overlapping patches where a single chart is poorly conditioned. Check orientation, inverse consistency and contact normals on transported patches. Register the individual rib and visceral meshes separately to the same world frame, and validate their relative positions. Surface transport alone does not give an interior organ registration.

## Minimal dynamic synthetic sensor

1. Represent relevant cardiac chambers and landmarks with a small number of geometric primitives linked by anatomical adjacency. Use a latent periodic phase for chamber centers and dimensions, with variable starting phase, rate and amplitude. The test planner sees time and its noisy observations. A measured phase signal, if used, must be available to every policy. For the liver and gallbladder, a separate common respiratory displacement is a reasonable first controlled setting.
2. For each actual probe pose, cast fan rays to task landmarks or mask pixels. Truncate or attenuate rays intersecting a rib mesh before reaching the structure. Start with geometric visibility and tune any acoustic parameters on phantom measurements. See [Bi et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC12905323/).
3. Intersect the visible geometry with the fan to obtain clean reference masks. Emulate detector outputs with a view-dependent, time-correlated loss process, positional and boundary jitter, label confusion and spurious components. Separate physical visibility, detector output and final confirmation in the evaluator. This isolates navigation and simulates the output of segmentation. A real B-mode experiment later runs a U-Net on the recorded or acquired frames, using only its output in the policy.
4. Calibrate on probe-synchronized clips with independently annotated identity, including obscured windows. Estimate visible-target recall, false detections, class confusion, centroid and contour error, and lengths of consecutive missing runs by scene and acoustic condition. Use distinct sweeps or physical phantoms for final paired closed-loop validation. Fixed image logs alone cannot provide outcomes for arbitrary counterfactual probe poses.

The first experiment in this directory retains the earlier finite-model ultrasound packet sensor. It has unordered centroids, shape-conditioned shadow, spatially coherent clutter, per-packet dropout, additional centroid noise and a scripted burst condition. It has no image-domain B-mode renderer, network or fitted real segmentation error distribution. The torso model above is a scoped design for a subsequent experiment.
