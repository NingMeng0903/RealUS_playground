ProDMP motion-layer validation
==============================

Scope
-----
This is an offline reference-layer audit.  The ProDMP is the original
integral-basis construction in the local material/body chart
``(x_m, y_m, yaw_rad)``.  A fixed audited ``T_world_body`` decodes it to a
world pose and analytic six-dimensional geometric velocity.  The dynamic
body-deformation transport experiment is separate and is not claimed here.

Mathematical contract
---------------------

* phase is ``s=t/tau`` and ``lambda=5``;
* four normalized RBFs have centers ``[.12,.36,.64,.88]`` and width ``55``;
* the normalized RBF mixture is gated by ``exp(-3s)``;
* each basis is integrated with the Green kernel
  ``(s-u) exp(-lambda (s-u))``;
* the 4x3 weight matrix is the Moore--Penrose minimum-norm solution for the
  endpoint position and normalized terminal velocity;
* physical velocity is ``dz/ds / tau`` and the world twist is obtained by
  left transport through the fixed anchor rotation;
* a same-pose entry in ``duration_matrix`` is ``0.1 s``.  Observation dwell is
  intentionally external to this travel-duration API.

Files
-----

* ``../motion.py``: implementation and stable ``reference`` /
  ``duration_matrix`` APIs.
* ``../test_motion.py``: mathematical and SE(3) contract tests.
* ``../run_native_motion.py``: optional deterministic native-QP replay only.
* ``native_results.json`` and ``prodmp_segment_*_trace.npz``: replay outputs.

Verification
------------

With the Genesis Python environment and pytest plugin autoload disabled:

``PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 /media/camp/EXT_DRIVE/envs/genesis/bin/python
-m pytest -q ../test_motion.py``

Result: 7 tests passed.  The checks include constraint rank/residual,
arbitrary endpoint velocities, independent DOP853 integration, independent
finite differences, common-anchor SE(3) pose/twist decoding, replan boundary
continuity, and the existing DMP duration baseline.

The optional run used the existing native binary and the existing scan replay
profile, with no hardware connection and no QP/controller edits.  It replayed
four short independent local segments from the public audited layout, with
``settle_s=0.1``.  Segment 0 (pure +x) passed the existing 2 mm / 2 deg
motion gate.  Segments 1--3 completed without solver faults or pauses but did
not pass that gate; their p95 position errors were approximately 8.56, 5.00,
and 4.54 mm respectively.  These failures are retained as controller/path
evidence, not hidden by retiming or QP changes.  This is not a claim that the
ProDMP layer or the native controller is globally validated.

Known boundary
--------------

The native replay is an ideal measured-joint deterministic model and excludes
physical latency, contact/force, ultrasound, and the dynamic material-frame
case.  The ProDMP reference itself passes endpoint and ODE contracts; the
mixed translation/yaw native failures are therefore evidence for the full
tracking stack and must not be relabeled as a mathematical endpoint failure.
