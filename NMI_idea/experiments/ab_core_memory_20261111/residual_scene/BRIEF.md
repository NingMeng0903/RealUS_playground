# 粗 ROI 内的连续几何与合成声学残差

独立测试集 `721219` 有 128 个对象。声学响应的角度斜率在探查和终端采集之间保持时，H4 比直接终端 H1 多通过 26 个对象，增加 **20.31 个百分点**（配对 bootstrap 95% 区间 13.28 至 28.13）。固定的正负成对探查已多通过 24 个对象，学习后验和不训练的解析差分均为 68/128。H4 比固定学习多通过 2 个对象，成功率差 1.56 个百分点（0 至 3.91），计入时间的效用差为 0.0150（−0.0012 至 0.0389）。本场景支持成对测量识别持久角度响应。固定探查已得到大部分收益，额外自适应深度的收益估计较小。

## 观测、动作和预测

一条连续血管沿局部 x 轴，横移和曲率独立采样。名义曲线与隐藏曲线分别送入旧 `observation/environment.py` 的 `_geometry_batch`，复用对连续折线的精确截面裁剪。隐藏实体门检查投影中心距不超过 2 mm、三维连续可见长度至少 15 mm、出平面切向 RMS 不超过 10°。终端的合成声学质量为 `−.20 + .09*tanh((投影长度−.018)/.015) + b + θ*(yaw/.10) + ε`，达到 0 即通过声学门。模型运行时只接收名义几何与探查发布的标量质量，训练输入只有多角度重复测得的公共质量。生成器使用独立高斯 `b`、`θ` 和 `ε`，标准差为 .065、.23 和 .035。

固定 `x=y=0`。起点 yaw 为 0，微扰为 ±.025 rad，终端为 ±.10 rad。旧 normal `T_world_body` 和 0.4 m 固定轨道下，五个端点均由 `CapabilityEvaluator._static_pose` 找到静态构型，最小自碰距离在 39.12 至 40.72 mm 之间。沿用旧积分基 ProDMP 的参考时长，探查驻留 .15 s，终端驻留 3 s。直接终端耗时 3.448 s，允许的三探查序列最长 4.571 s。每个策略共享 5.4 s、一个终端和最多三次探查，三次上限由实验设定。机器人的证据范围是有限 IK 搜索得到的单端点 FK、限位和配置自碰检查，以及离线 ProDMP 参考时长。声学结果来自合成观测。

训练用 `721210` 的 384 个独立对象，每个对象在五个角度各重复四次。先用同对象同角度的重复量估计测量噪声，再从对象级截距和斜率样本协方差中扣除测量噪声贡献。估计得到 `b, θ` 均值为 `−.00162, .00299`，噪声标准差为 `.03513`，先验标准差为 `.06476, .22184`。条件更新累加 `xxᵀ/σ²` 和 `x(Y−g_nominal)/σ²`，一次平衡探查对将模型标准差降至 `.02319, .09067`。解析对照直接用正负校正读数的均值估计 `b`，用差值除以 `.50` 估计 `θ`，由外推质量选择终端。

H1–H4 共用这一条件模型和 `成功概率 − .04 × 秒数` 的目标，深度分别允许 0、1、2、3 次探查。Gauss–Hermite 在公共预测分布上积分下一次读数，25 点下的根期望效用为 H1 `.1755`、H2 `.3264`、H3 `.4071`、H4 `.4126`、最佳固定对 `.4066`。41 点复核的四个根动作一致。重采样模型下直接根效用 `.1742`，最佳首次探查根效用 `.1682`。开发集 `721211` 先运行，代码、模型、开发结果和机器人记录的散列写入协议后才生成测试集。区间以同一对象为单位配对重采样。
