原 B 的自主探查、停止与受约束执行：Astra 理论复核和下一轮小协议
2026-11-11
状态：设计与解释；未新增训练，未运行本协议，也没有新的成功结果。
只新增本文件，不修改已有结果或生产代码。

一、建议直接回应用户

你要的是原 B 的完整目标：系统根据已有观测、实际机器人状态和后续
任务条件，自己决定接下来怎么探、探多久、何时转入正式采集，以及
何时退回或承认当前做不成。不是要求系统在我们规定的 5 秒钟内停止。

5.290 s 是从公共 native 路径时间构造的机制见证：中央探查后两边
来得及，某侧探查后的跨窗来不及。它不是系统学出的时间、临床阈值，
也不是 B 的核心创新。该见证用于隔离机制，不应变成目标系统的定义。

现有结果不能解读成“B 已经明显有用，只要多给一点时间”。主截止 B
与强 A 同为 78/256；到 5.850 s 是 B 136、强 A 88、完整双倾转 133；
到 7.800 s 则是 B 153、强 A 159、双倾转 155。时间和可恢复性改变了
策略排序。中等预算有优势，不等于预算越宽 B 越好，也不等于学习策略
已经优于简单完整探查。另一方面，这个偏小的截断实现也没有检验完
原 B 的自主探查与停止目标，不能拿它判定完整 B 理论失败。

已经比较扎实的是较窄的机制：从同一实际探查出口出发，读新观测能
改善后续新采集；在来不及切换的出口，这种增益消失；保持同一观测和
截止，打开真实跨窗路线后，增益恢复。它支持“探查应面向后续任务”，
不直接证明某个完整探查策略、学习架构或停止规则已经学成。

二、当前什么由系统决定，什么没有学到

手写/冻结：两窗和诊断位置、正负倾角、单探与双探程序、0.15/0.30 s
诊断 dwell、1 s 终端 dwell、最多两次终端、几何/质量验收、公开停止
阈值，以及机器人路由和时间模型。5.290 s 来自公共时间公式。

在线估计：根据实际声学包更新局部 w 的关联混合与高斯自然参数。
这是数据驱动的在线贝叶斯辨识。当前共享先验和观测规律来自声明的
模拟模型，不是已在独立真实超声数据上训练出的响应网络。

在线规划：对有限候选枚举可能的公开观测，算预期终端价值，选择首
动作；执行后从实际 q、qdot、耗时重新选择合法终端。这个选择是程序
自动做的，却不是训练得到的 policy。选择了双探后，当前实现不会在
第一张诊断图之后重新决定是否继续第二张；探查时长也不是自由决策。
第一阶段只计一次终端，而执行允许第二次重试，未来价值仍被截断。

所以回答是：已有“自动决策”和“在线参数估计”，没有“学会探查时长
与自适应停止的完整策略”。自动决策不必通过 RL 才能实现。先学习/校准
动作响应，再在线规划，也可以让系统自主决定动作、时长和停止；端到端
RL 则是另一个需单独证明收益的实现方式。自主停止本身是通用决策机制，
这里应把它作为实现原 B 的必要部分，不作为另造的新理论名词。

三、保留前两式，只把第三式改成自主选择停止时刻

前两式保留原职责，不增加网络要求：

  Y_a = g_geo(S,Fhat^{-1}A_a) + H_xi(a) w_xi + epsilon_a，H=[1,s_a]。

  Lambda_xi = Lambda_xi^- + Σ H_i' R_i^-1 H_i，
  eta_xi    = eta_xi^-    + Σ H_i' R_i^-1(Y_i-g_i)。

它们分别描述可预测的局部响应与已取得证据的累积。高斯式仍只在给定
几何/关联分量的条件下精确；丢失、假目标、几何不确定性由对应混合
或离散假设权重保留，不能凭一个很小的参数方差宣布任务已可靠。

第三式精简为：

  (mu*,tau*,pi*) = argmax E[ p_fresh(pi | b_tau,x_tau,r_tau)
                             - lambda C(mu_[0,tau],pi) ]
  over public-history probe policies mu, stopping times tau,
       and pi in Pi_checked(x_tau,r_tau),
  subject to: if committing to execution,
              lower_p_fresh(pi | b_tau,x_tau,r_tau) >= 1-delta.

mu 决定下一小段的位姿、方向和采集时长；tau 是由实际公开历史决定的
停止探查时刻，不是给定秒数；pi 是停止时从实际状态出发的完整后续
执行策略，包含任务所允许的验证、失败恢复和重试。每个不同观察分支
可以选不同 pi，同一公开历史必须作同一选择。r 是尚可使用的资源，
可以包含接触/风险/能量预算；没有硬时间限制时不必包含截止倒计时。
C 计入已用探查、运动、后续执行和恢复成本。合法退回/放弃也在选择
中，任务收益记零并计入全体病例失败/放弃率，不能靠永不执行来获胜。

p_fresh 是“这条后续策略在声明约束下实际取得新的、正确、合格目标
观测”的概率，而不是参数被识别、看见候选或当前图像置信分数的概率。
lower_p_fresh 是经独立执行数据检验的保守预测；模型失配、支持不足时
不能凭后验自信自动当成可靠。它是可检验的风险预测，不是没有条件的
逐患者保证。硬运动约束仍由实际轨迹检查负责，不能由概率高来豁免。

delta 是任务方给定的可接受失败风险，验收标准也由任务定义。系统可以
学习如何达到该要求，不能为了提高成功率数字而自行放宽要求。阈值
校准可用独立开发数据按预定规则做，但不能在测试结果上挑容易过的
阈值。不同风险要求应报告完整的覆盖率、错误承诺率与成本曲线。

执行时等价于每得到一包观测就比较三件事：再探一段能否值得其代价；
当前是否已有足够可靠且可执行的完整续行；是否应先退回/重定位或放弃。
停止来自这个比较。它既不是“方差低于阈值就扫”，也不是“等待够久”。

必须分开两种停止：第一种是停止探查、放行后续扫描，依据上述未来
任务成功预测和继续探查的价值；第二种是宣布成像任务完成，必须有
新取得的实际观测通过目标身份与图像/特征质量验收。预测再自信也不
等于已完成任务。当前代码检测到且 quality>=0.58 的公开停止规则属于
第二类的一个不完美检测器，仍产生错误停止；它不是第一类已经校准的
任务可执行成功置信，不能拿来声称系统已学会何时结束探查。

四、不依赖硬截止时，什么还能区分 B

如果环境静态、所有合法探查可逆、路线可遍历、重试没有代价，并且
存在可到达的合格视图且重复采集有正成功概率，那么足够持久的公平
搜索也可能最终成功。此时用无限时间的最终成功率很难区分 B 和强 A；
应看达到同等风险与覆盖率所需的观察数、移动、接触负担或总时间。
若所有这些代价也都人为设为零，就不应要求必然存在 B 的最终成功率
优势。该判断依赖以上条件，不覆盖不可辨识、不可达或持续模型失配。

尤其在静态可逆系统，若能沿原路回到探查前状态，再走原先合法路径，
一个“探查后进了死胡同”的图示不能证明永久失去任务能力。现有墙
大部分正是多绕路；native 某个固定参考失败也不是所有连续路径不存在。
不能再手工删回程边，或添加未经验证的不可逆机理来保证 B 胜出。

需要区分三种诚实反例，分别报告证据等级：

1. 端点都可达，但要求的整段连续采集无合法关节/接触路径。约束必须
   来自明确任务和几何/动力学，给出具体失败点及可行替代路线；若只
   做有限搜索，说“当前控制器/库无见证”。若允许退回重试，就把它算
   进去；没有实际不可逆性或代价，不能升级为无限时间必败。
2. 再探或换窗会耗掉真实非时间资源，如接触次数、累计负荷、可接受
   失锁风险或一次性任务机会。资源更新、允许恢复、风险估计必须有
   物理/任务依据，预算对所有方法相同。仅把“最多探两次”换个名字
   不构成新物理证据；若组织可恢复，恢复动作和代价也必须开放。
3. 某声窗的必要入射姿态/接触模式在当前机器人状态下没有安全见证，
   虽然解剖判断已经准确。若另外声窗/重定位可行，完整后续要包含它。
   若所有可用终端都不合格，各方法都可能应拒绝执行，不能强造 B 成功。

这些情况说明“知道该做什么”与“能够可靠做成”不同，但不会自动给出
某一 B 算法的优势。下一轮只在已有可信模型能表达时运行；否则明确
保留为未实现的物理验证，不拿抽象约束冒充已经测到的临床限制。

五、最小必要实现

1. 将双倾转拆成单次可中断采集，在每次实际观测后重新规划。复用当前
   signed tilt、材料状态、ProDMP、dIRD 和 native 检查器。初版时长
   候选为 0.15、0.30、0.60 s；移动时间由实际动作决定，不可免费缩短。
   这先实现自主选择离散时长与探查次数，不声称学得任意连续波形。
2. 补齐任务预测：同时保留公开几何假设及条件响应状态；目标/杂波
   采用同一可见字段。完整执行 option 包括行进、新采、公开验证、
   允许的失败重试和退出，其概率与成本全部进入首阶段评分。采用
   已收敛积分/小问题穷举校验；不能再次以粗积分造成的排序当机制。
3. 在独立开发轨迹上校准“选中并承诺执行的整个 option”的完成概率。
   校准数据必须包含由探查策略实际选择的入口、低质量包、失锁和恢复。
   仅校准单帧检测概率或参数方差不够；分布外入口报告支持不足。
4. 先用普通低维模型学习未知响应/可见性/误差统计，在线估计个体状态，
   再用上述规划器决策。共享响应模型在测试时固定；测试真值只进验收。
   这叫 learned response + planning。只有在线搜索成本或远期策略确有
   瓶颈时，再比较直接学习动作/终止的 policy；同观测、动作、数据和
   预算下不胜过该规划基线，就没有引入端到端 RL 的实证理由。

六、冻结下一轮小协议：先检验自主停止，不再选有利秒数

本文件冻结问题、权限和评价规则。代码与动作/模型清单须在新测试前
另行封存；这里没有声称新增接触动力学已经可运行。

对象与拆分：沿用现有两个镜像 fixture 及开放控制，独立生成训练
512、开发/校准128、测试128个对象，种子依次721501、721502、721503；
测试噪声721504。全部策略按对象配对；两个镜像仍算同一统计对象。
若共享模型已有合格独立训练集可直接冻结复用，不把测试病例拿去补训。
无患者预扫描，不以私有中心线配置初始动作。

动作：当前可执行单探位置/倾角 × 三档 dwell；每次采集后允许继续
单探、换窗、开始完整采集 option、或共同合法退出。完整 option 在
正式封存前明确重试上限及公开停止条件，所有策略完全相同，首阶段
对其全部分支计价。不能给 B 多一次免费采集或更丰富的恢复动作。

主场景：取消硬任务截止，主验收以任务可靠性和正确执行覆盖率优先，
时间完整记录为次要指标，主分析设 lambda_time=0。最简决策顺序是：
先满足共同的任务风险要求，再比较可实现的正确执行覆盖；风险与覆盖
相当时，优先减少新增探查和动作负担。已有合格完整续行、再探不改善
这个目标时转入执行，否则继续探查或合法退出。不得仅为省时间而降低
主验收要求，也不能靠大量拒绝把表面可靠性抬高。
第三式的成本权重保留为参数；0.04/s 仅作为预先声明的次要时间偏好
敏感性，与 lambda_time=0 一并报告，不作为用户的默认偏好。另报
原始时间、距离、帧数及恢复负担，不为它们擅自指定临床交换比。
风险容忍示例 delta=0.10，在看测试前固定；0.05、0.20 为预定敏感性，
不能选择胜率最高者当主结果。若所有代价都设为零、只问无限时间的
最终成功，可能没有唯一的有限最优停止时刻；可明确使用共同的平局
规则或记录未决，不能声称系统必然学出某个秒数。
调试防死循环上限只作计算 watchdog；触发记为未决/截尾并单列，
在任务完成统计中未取得合格新观测就不计成功，但不把触发时间当作
学习出的停止时刻或物理任务截止。终端验证标准在封存时对所有方法
同一，不能通过更宽的 B 验收制造成功。

对照至少包含：
  A：完整共同信念的即时采集选择，实际状态合法恢复；共享同一风险
     校准、执行/退出条件和计算预算。
  固定：在独立开发集确定的成对倾转及重复次数/时长，然后用相同
     后验与执行规则；无硬截止下必须允许完整执行它，不能靠回退削弱。
  B：同一响应模型与动作库，依据未来公开观察分支自适应选择下一段
     及停止。另做“冻结同首动作、只遮新包”的实际续行配对。
  B_nominal：动作库、积分精度、停止规则相同，首阶段用名义后继状态，
     实际执行仍合法重规划，用于单独检验执行预测。

如要评价学习增量，再给 A/B 同时换成解析或学得响应模型；不要把
“B 多了训练数据”混进未来规划的增量。端到端 RL 不列为本轮必需项。

主要报告：全体对象的正确新采集率、错误承诺/错误停止率、退出率，
以及实际运动+采集+规划成本；在同风险要求和相近覆盖率下比较成本。
同时报完整风险—覆盖率—成本曲线，防止较保守拒绝看似更可靠。
概率预测要在被选中执行的病例上与真实完成结果对照，给出校准误差
和样本区间。对象级配对 bootstrap 10000次、种子721505；所有病例、
模型失败和 watchdog 触发均保留。不要把重复帧或固定机械轨迹当新对象。

必要负对照：无信息；目标已可靠确认；稳定响应被重置且分别告知/
不告知；可逆开放且代价趋近零。最后一项预计最终成功率差会缩小，
若确实缩小应视为符合机制，而不是重新设置一个紧截止挽救差异。

非时间约束扩展另设资格门：先用公共几何/物理开发数据证明所声称的
连续路径失败、资源消耗或不可恢复模式真实存在，并保留全部恢复路线；
未满足就不运行这一扩展。不能按“B 是否胜出”选择或保留布局。

否证标准：B 若仅多采几帧而同成本不优、仅更多拒绝、校准失败、依赖
假死路/隐藏真值/粗积分，或可完整执行的固定对照达到同等任务风险和
成本，则不支持相应 B 增量。反之，只有在相同风险与权限下，确实用
更少负担完成相同任务，或在有独立依据的资源约束下完成更多任务，才
支持完整自主探查与停止的实用价值。结果可以为零，不保证 B 获胜。
