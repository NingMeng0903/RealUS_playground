# Policy mechanics check (read-only source audit)

核查对象：`ab_closed_loop_reviewed_20261111/{planning.py,run_closed_loop.py,acoustics.py,fixture.py,robot_motion.py}`。候选的声学 dwell 由程序常量规定，B 只能在有限 program（及其总 event 时长）之间选择；它不能在 program 内每个 packet 后自适应改 dwell 或提前结束。因此“声学 dwell”和“机器人从当前状态走到采集位的总 event 时间”不是同一个数，也不表示模型已经学会了“探多久”。

## 1. 候选动作、时长和 dIRD

候选不是由 dIRD 临时生成的。`Rig.captures` 固定 side_left/right、fork_minus/plus 和 terminal 的局部目标；`Rig.programs` 固定单探查和两种 pair 顺序（[fixture.py:121-149](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:121>)）。声学 dwell 常量是 side=0.15 s、fork=0.30 s、terminal=1.0 s，settle=0.12 s（[fixture.py:25-40](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:25>)）。实际 planner 动作由 `action_at` 从执行后 pose 和 measured frame 组装，`ProbeAction.duration_s` 使用这个 capture dwell（[planning.py:51-55](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:51>)）。

总 event 时间由公开的 `segment_duration`/`timed_route`（最低0.55 s、距离/转角速度项、每段加0.12 s）预测（[fixture.py:87-95](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:87>)）；真正执行时 fork 另有至少0.80/1.10 s 的 reference 下限，最后一段 settle 再加 dwell（[fixture.py:299-313](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:299>)）。因此当前受限 fixture 的已校准总时间为：单 side 1.53/1.595 s，单 fork 1.225 s，pair 2.75 s；direct terminal 2.60/2.675 s（[closed_loop_reviewed_run/fixture_00_constrained/FROZEN.json:161-248](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_20261111/closed_loop_reviewed_run/fixture_00_constrained/FROZEN.json:161>), [fixture_01_constrained/FROZEN.json:161-248](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_20261111/closed_loop_reviewed_run/fixture_01_constrained/FROZEN.json:161>)）。`acoustics.fixture_actions()` 中的 0.72/0.86/0.94 s 是另一套 canonical action（[acoustics.py:114-124](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:114>)）；当前闭环 planner 没有导入它，实际使用的是 `Capture.dwell_s`。

dIRD 只做候选 route 的 batched margin 排序：先把各 route waypoint 转为 measured-frame TCP poses，调用 capability score，再按粗粒度时间、负 margin、实际时间、名称排序（[fixture.py:271-297](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:271>)）。所有 route 仍可尝试；实际通过 native trace、tracking、pause、exit-state 和 workspace 检查决定 valid（[fixture.py:315-378](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:315>)）。`screen_dird` 也只是返回屏蔽前的 batched 分数并记录，不是完整路径证书或终止门（[robot_motion.py:271-312](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/robot_motion.py:271>)）。

## 2. 是否“模型自己学来”：没有训练；只有固定先验上的在线后验更新

隐藏 response `w=(b,beta)` 在每个 scenario 直接从零均值、SD=(0.065,0.23) 的 Gaussian 采样（[acoustics.py:21-24](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:21>), [acoustics.py:208-223](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:208>)）；planner 的 `MixtureAddressMemory` 用同一固定 prior 初始化，未见训练集、梯度或网络参数（[acoustics.py:400-427](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:400>)）。在线部分是每个事件一次的 Gaussian natural-parameter update（[acoustics.py:366-380](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:366>)），association mixture 对 candidate 分成 target/clutter 分支；target 分支更新，clutter 保留原参数，missing 只按 detector law 更新权重（[acoustics.py:461-495](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:461>)）。

likelihood 来源全是代码内固定模型：`H=[1,yaw/0.10]`（[acoustics.py:513-517](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:513>)；quality 是 nominal geometry + `H w` + duration-scaled Gaussian sensor noise（[acoustics.py:234-249](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:234>), [acoustics.py:277-301](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:277>)；supported genuine detector=0.80×geometry support、clutter=0.10×miss remainder，预测用 5 个 target / 3 个 clutter quadrature nodes（[acoustics.py:452-459](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:452>), [acoustics.py:589-624](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:589>)）。探查 packet 仅在 informative 或 terminal 时 assimilate；I=0 只屏蔽诊断包，terminal 仍可读（[planning.py:62-65](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:62>), [run_closed_loop.py:202-207](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:202>)）。

## 3. 选择、停止、重试和 5.290 s

`B_I1_F1` 的首选不是固定“探多久”：`choose_initial` 先把 direct terminal 的 `success-probability - 0.04*time` 作为 baseline，再对每个有限 program 用 `value_after_observations` 做候选 outcome 的期望后验价值，并扣 program 时间（[planning.py:175-181](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:175>), [planning.py:192-234](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:192>)）。实际执行后从真实 state、belief、remaining time 重新选 immediate scan（[planning.py:237-239](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:237>)）。

公开 stop 门是 detected 且 confidence≥0.65 且 quality≥0.58（[run_closed_loop.py:130-131](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:130>)；真实 terminal acceptance 还要求 hidden kind=target、center≤4.5 mm、axis≤0.22 rad（[acoustics.py:331-346](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/acoustics.py:331>)）。公开不满足 stop 时，最多再试一次 terminal（`MAX_TERMINAL_CAPTURES=2`）；每次都要剩余时间容纳 checked continuation，否则在 next-capture 或 actual exit 处 timeout（[run_closed_loop.py:23-28](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:23>), [run_closed_loop.py:156-225](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:156>)）。

5.290 s 不是手填常量，也不是声学结果拟合出来的；它来自实验者预先定义的 `witness_deadline()` 规则，与模型自主学得的时长或在线停止无关。该函数由已校准 public native 时间找 central program 的最小最坏完成时间 `c` 和 side program 跨窗时间的最小值 `s`，只有 `s-c > 0.01+2×0.020` 才设 `(c+s)/2`（[planning.py:138-157](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:138>)）。fixture_00 的 `c=4.215,s=6.365`，故 `(4.215+6.365)/2=5.290`；manifest 只记录该生成值（[fixture_00_constrained/FROZEN.json:235-248](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_20261111/closed_loop_reviewed_run/fixture_00_constrained/FROZEN.json:235>)）。注意 primary `T0=3.900` 是另一条规则：`max(direct terminal)=2.675 + min(valid program)=1.225`（[planning.py:92-95](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:92>)；[fixture_00_constrained/FROZEN.json:161-235](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_20261111/closed_loop_reviewed_run/fixture_00_constrained/FROZEN.json:161>)）。fixture_01 的 witness 是 4.835 s，不是固定 5.290（[fixture_01_constrained/FROZEN.json:235-248](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_20261111/closed_loop_reviewed_run/fixture_01_constrained/FROZEN.json:235>)）。

## 4. 后续确实使用实际 q/qdot；dIRD 不是唯一控制

每段 continuation 的 entry 是上一段完整 native snapshot；`execute` 由 state.q 启动并把 snapshot 作为 `initial_state` 传入 replay，返回 q/qdot/acceleration exit（[robot_motion.py:197-210](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/robot_motion.py:197>), [robot_motion.py:285-312](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/robot_motion.py:285>)）。`execute_local` 用 FK(current q) 作为真实起点，而非假定目标 pose（[robot_motion.py:314-339](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/robot_motion.py:314>)）；每个 route 完成后把 `MotionState.from_result` 放回下一 state（[fixture.py:344-367](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:344>)）。planner 还逐项核对 continuation trace 的 start_q/start_qdot 与当前实际 state（[planning.py:122-131](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:122>)）。

## 5. 去掉 deadline 不能绕过全部控制约束；只能放宽时间 admission

无穷 deadline 会让 `scans` 的 remaining-time 筛选和 episode 的 deadline 分支基本不触发，但仍保留：局部窗口/障碍与线段清障（[fixture.py:167-185](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:167>)）；actual trace 的 workspace、swept wall、≤3 mm synthetic gap（[fixture.py:242-252](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:242>)）；native tracking、same-tick alignment、pause、exit-state-valid 等 gate（[fixture.py:315-330](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/fixture.py:315>)）；native execute 的 solver/tracking/constraint 汇总门（[robot_motion.py:296-312](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/robot_motion.py:296>)）。反过来，dIRD margin 本来就不是硬 gate，jerk margin 只记录不 admission；代码也没有“去 deadline 后改成任意连续动作”的路径。有限候选库、最多两次 terminal 和既有 route fallback 仍在。

## 6. Strong A、pair 公平性和边界

`A_greedy` 在首步直接选 best immediate terminal，不做 probe lookahead；后续与 B 共用 actual-state `choose_continuation`、公开 stop 和 retry 代码（[planning.py:209-213](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:209>), [run_closed_loop.py:156-225](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:156>)）。`A_geometry` 的实际差异是排除 online acoustic assimilation，不是另一个已实现的连续几何 servo（[run_closed_loop.py:202-207](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:202>)）。`pair_fixed` 的顺序在私有 draw 前按 public checked worst-case completion 选；若完整 pair 放不进 deadline 就 fallback 到 direct（[planning.py:96-105](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:96>), [planning.py:213-219](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:213>)）。

公平性实现包括：同一 `Acquisition`/scenario 贯穿同 variant 的各 arm（[run_closed_loop.py:261-290](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:261>)）；forced same-first I0/I1 在相同 prefix 后只改变 packet visibility，并强制检查 exit signature 相同（[run_closed_loop.py:281-293](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:281>)）；初始选择 wall time 按 variant/method 预先 profile 并计入各 arm（[run_closed_loop.py:261-280](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:261>)）。边界是固定有限动作/route catalog、合成 feature observation（非 raw ultrasound/hardware），dIRD 仅排序，且当前 initial value 只对未来 probe outcome 做有限 lookahead；实际最多在公开拒绝后再采一次 terminal（[planning.py:192-205](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/planning.py:192>), [run_closed_loop.py:156-225](</media/camp/EXT_DRIVE/RealUS_playground/NMI_idea/experiments/ab_closed_loop_reviewed_20261111/run_closed_loop.py:156>)）。
