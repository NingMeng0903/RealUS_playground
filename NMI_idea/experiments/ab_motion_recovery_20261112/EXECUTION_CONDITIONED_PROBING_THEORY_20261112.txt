状态：条件性数学推导与研究设计。本轮未新增闭环或实体实验；未证明完整 B 优于强 A；未宣称以下通用统计工具具有原创性。

1. 研究问题

只使用一个脏器局部及内部特征，不依赖血管、肋骨或患者移动等特定场景。
任务是完成规定的新区域覆盖或特征切面序列。任务标准、接触限制、机器人
原生约束、双方允许的回撤与恢复程序在比较之前共同声明。

中心问题：探查要让哪些不确定性缩小到什么程度，才能从实际出口可靠继续？
一次探查同时改变已有证据和机器人完整状态。更多信息不必带来更多续行能力。
停止不要求识别全部解剖或选出所有相容世界共同的精确最优动作，而要求至少
有一个共同允许的程序满足任务标准。可靠完成优先，探查和恢复负担为次级量。

2. 三个核心关系

式一：由已执行动作与公开观测建立可反复检验的证据集。

  z_i = y_i - g_geo,i = H_i theta + epsilon_i,
  V_t = V_0 + sum_i H_i^T R_i^{-1} H_i,
  C_t = {theta : ||theta - theta_hat_t||_{V_t} <= beta_t},
  P(theta_star in C_t for all t) >= 1-delta.

theta 是声明的局部内部特征/响应系数。冻结分割提供边界、中心、方向等特征，
H_i 由实际测得的位移、转角、接触条件和校准模型计算。g_geo 使用粗先验和
可观测的当前几何，绝不能读取模拟器真值。置信集须对自适应选视图及停止
时间有效；固定时刻的 Gaussian 置信区间不能直接承担反复检查的保证。

上式仅表示有正确关联、声明噪声/残差条件的局部子类。相邻帧相关性应进入
联合噪声模型或合适的序贯置信构造。同一事件仅计算一次。未检出不是零位移
观测；误检/错关联和响应漂移必须单独建模或计入覆盖失效风险。手设宽先验
不能自动解释成具有真实人群覆盖率的置信集。

式二：将证据投影到实际续行需要的方向，计算可靠继续的余量。

对完整出口 x 和已声明、已检查的续行/恢复程序 u，把局部任务的充分条件写为
  l_j(x,u)^T theta + rho_j(x,u) <= b_j(x,u), for every j.
其中 rho_j 为该局部模型、跟踪及连续段近似的保守余项。
定义
  G_t(x,u) = min_j [b_j - l_j^T theta_hat_t
                    - beta_t sqrt(l_j^T V_t^{-1} l_j) - rho_j].
  G_t(x,u) >= 0  =>  该程序在 C_t 内可认证。
  tau = inf{t : exists u in F(x_t), G_t(x_t,u) >= 0}.

l_j 指出任务依赖哪个未知响应方向，b_j 表示该续行能容许的误差/纠正范围。
这些量不能由 dIRD 分数或一条通过的 native 轨迹直接冒充。要从局部成像模型、
任务容差和共同执行器中构造，并给出适用范围。有限程序库之外不作全局结论。
当前 native 离散检查也不自动成为连续路径的鲁棒证明。

若 C_t 是完整椭球，式二是线性约束在椭球上的精确最坏值计算。若另有先验
支持限制，使用整个椭球可能保守。式二对真实非线性任务仅在上述约束确实
足以保证任务、且余项有效时为充分条件；不能把未通过证书等同于任务不可能。

式三：与实际出口相关的有限探查条件。

考虑一个合法可重复、可返回指定出口 x_bar 的探查程序及续行 u。
令 m_j = b_j - l_j^T theta_star - rho_j > 0。
若探查的信息增长满足 V_n >= n M（PSD 次序），且 l_j in range(M)，则

  n >= 4 beta_n^2 max_j [ l_j^T M^dagger l_j / m_j^2 ]

足以使式二成立（在式一的共同覆盖事件上）。n 是有效观测单位，不是固定秒数。
若 beta_n^2 = O(log n)，该界在有限 n 可以满足。不必辨识 l_j 所在子空间之外
的所有未知量。这个界用于分析；在线停止使用式二，不假装提前知道真实 m_j。

证明：|l_j^T(theta_hat_n-theta_star)| <= beta_n sqrt(l_j^T V_n^{-1}l_j)。
式二再扣除一个同样的半径，故 G >= min_j[m_j-2 beta_n sqrt(l_j^T V_n^{-1}l_j)]。
由 V_n >= nM、l_j in range(M)，有 l_j^T V_n^{-1}l_j <= l_j^T M^dagger l_j/n。
合并即得。没有严格余量、有效采集率或相关方向激励时，不提供有限时间保证。

3. 探哪里、探多久、何时继续的实际规则

输入是完整合法观测历史的证据表示、实际接触标架、当前机器人完整状态和任务。
候选可包括继续采集、短平移、倾转、重定冗余构型和合法回撤。探查与扫描可以
同时积累证据，不强行划成看到目标/失去目标两种互斥阶段。

首先计算当前已检查程序的 G。若存在合格程序，选择并执行它，后续每份新
观测继续检查模型和任务条件。否则识别限制 G 的方向，预测候选对这些方向
的信息作用及其完整实际出口，比较合法的“动作—观测—续行/恢复”程序。
开始时可以用小候选库和有限树搜索；每执行一个短段，以真实观测更新，再
判断是否已够。时间不使用人为硬截止，但相同可靠性下应减少无用采集和回撤。

不能只做当前信息量的贪心优化：某些低信息动作可能为了到达有用视角或保留
出口而必要。有限停止命题针对满足激励与可返回条件的程序，不是对任意贪心
实现的收敛证明。局部可行不自动保证未来仍有充分的探查能力。

学习与规则的分工：可以离线学习局部响应/特征基与探查程序的候选排序，也
可以蒸馏可靠规划器的策略。第一版推荐规则候选+可学习响应+在线停止证书。
策略输出只是提议，实际响应及出口重新检查。若要把 RL 本身写成贡献，应有
其独立增益，不能把学习策略存在当成置信或执行保证。

4. 最小二维例与恢复反例

这是手算机制例，所有量按各自工程单位归一化，不是本轮 native/实体结果。
同一份证据的椭圆中心为零，两方向半轴为 (0.25, 1.00)。

出口/当前选定续行     可容许第一方向误差   可容许第二方向误差   当前证书
x_A                    0.50                1.25                 通过
x_B                    0.50                0.50                 不通过

x_B 重复观测第一方向不能消除第二方向造成的证书缺口。第二方向半轴缩至
0.50 即可使此中心不变的例子通过；归一化精度须增加至四倍。若固定 beta 的
示意设计在该方向具有 1+n 的信息精度，需增加 3 个信息单位。真正自适应停止
必须计入 beta_n 的增长与均值变化，不能把这里说成“三帧一定足够”。

反例是必要的：如果 x_B 可无新观测安全返回 x_A，则“返回再续行”是合法
程序，强 A 与 B 都可用。纳入共同恢复后，x_B 也能完成，只是付出恢复负担。
因此单靠这个二维例不证明最终成功率分离。更一般地，若一条不需新证据的
合法转换可到达已有可靠续行的状态，程序串接就给当前状态一个可靠恢复方案。

若所有允许探查对两种相容状态产生相同观测分布，而两个状态没有共同合格
的续行/恢复策略，则再多观测也不能保证选对。零空间只能提示这种歧义；要
宣布整个任务不可能，须证明歧义对所有共同允许策略仍然存在，不能只看一条路。

5. 最小验证设计，不扩场景复杂性

固定单个脏器体模/模拟器及内部特征，固定已完成前段提供的标定 masks 历史。
先从独立机械/成像标定得到局部响应和续行余量，冻结它们再跑策略。用同一
内部特征、同一任务和同一证据，只改变真实合法出口或初始冗余构型。
检测能否预先预测缺信息的方向、所需观测量、何时可继续。操纵观测方向、
误差幅度和真实执行余量，不叠加患者运动、肋骨或多个故障。

共享分割、全部历史、动作库、恢复权限、原生执行器和判据。比较强 A、完整
成对倾转、B、名义出口 B，以及能使用同样方向证书的强经典规划器。
若简单规则或经典规划器匹配 B，应记录同等结果。

核心证据：证书是否正确预告续行；相关方向探查是否比无关方向真正补足缺口；
改变出口后是否确实改变缺口；全部共同恢复后最终正确覆盖/错误认证/未决率。
采集数、路径、接触和回撤负担另报。不能把局部证书未通过改称最终任务失败。

6. 现有模块的精确角色

harmonic/SMPL-X：材料地址维护证据身份和跨姿态查询，实际动作使用测量的
接触标架。身体标签持续不等于内部组织位置或响应永远不变。

等变性：对 theta'=S theta 的可逆坐标变换，l'=S^{-T}l、V'=S^{-T}VS^{-1}、
theta_hat'=S theta_hat，使 l'^T V'^{-1}l'=l^T V^{-1}l，证书不变。
这是共同坐标变换下的精确关系。患者相对机器人改变姿态时，实际能力仍须重算。
非刚性组织变化不是自动满足同一刚体对称性的场景。

e3nn：可用于类型正确的局部响应共享；解析标架运输与局部坐标网络也可能
满足相同合同。当前证书不要求某一个网络库，不能宣称其必要性已证明。

ProDMP：参数化合法短段和重规划参考，不自动给出成像成功或机器人执行保证。
dIRD：提议/排序机器人实现，不把代理能量当成鲁棒续行集合。
native 控制器：执行与局部能力标定。保持现有物理约束与合理偏好，不增加
人为关节硬墙；不扩成证明全局连续可达的新任务。

7. 理论意义与未完成部分

可在声明假设下证明：自适应观测/停止的可靠性、任务相关激励的有限停止充分
条件、无效方向的不可辨识见证、恢复闭包反例、正确运输下的证书坐标一致性。
这些主要使用已有统计、稳健优化和线性代数工具，不等于已经取得原创理论。

最值得争取的贡献：从标定超声和真实执行模型构造紧、可计算、可验证的
l_j,b_j,rho_j，并构造在约束下接近必要观测量的探查程序。要证明“缺什么
信息”和“从哪里取得且仍能继续”，而非仅把 posterior、dIRD 和 MPC 相连。
当前尚未完成上述物理构造与近必要性的理论，也没有本轮 B 最终成功率结果。
