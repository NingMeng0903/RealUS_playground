# Related work for active reinspection

| Work | Relevance to B |
|---|---|
| [Chaplot et al., Active Neural Localization, ICLR 2018](https://openreview.net/pdf?id=ry6-G_66b) | A structured location belief and a policy choose which observations to acquire in aliased mazes. The environment map is given. Here the internal geometry, connection and return identities are uncertain, while probe poses are measured. |
| [Chaplot et al., Learning to Explore using Active Neural SLAM, ICLR 2020](https://arxiv.org/abs/2004.05155) | A high-level selector reuses mapping and path planning. The analogous interface is a learned scan target or checked sweep with the existing low-level executor. Coverage alone cannot score identity-correct inspection. |
| [Lazaro-Gredilla et al., Fast exploration and learning of latent graphs with aliased observations](https://arxiv.org/abs/2303.07397) | Explicit alternative latent graphs drive exploration under repeated ambiguous observations. In ultrasound, the latent anatomy can differ while the robot's checked movement graph stays fixed. |
| [Chen et al., Autonomous Exploration Under Uncertainty via Deep Reinforcement Learning on Graphs](https://arxiv.org/abs/2007.12640) | Graph-structured RL can amortize online search across randomized environments. A learned graph selector alone has direct precedent. The task endpoint and observation model would have to supply the specific contribution. |
| [Pathak et al., DA-BSP, IJRR 2018](https://journals.sagepub.com/doi/10.1177/0278364918759606) | Predicts multiple data-association modes during belief planning. This is a direct precedent for all-candidate association and action-conditioned future beliefs. [D2A-BSP pruning work](https://arxiv.org/abs/2303.02139) further addresses controlling growth of the hypotheses. |
| [Javdani et al., Bayesian active learning for decision making, AISTATS 2014](https://proceedings.mlr.press/v33/javdani14.html) | Observations can identify an adequate decision region while leaving state hypotheses unresolved. The inspection problem adds mechanical reachability, remaining resources and a required new observation as part of the continuation. |
| [Sunberg and Kochenderfer, POMCPOW and PFT-DPW, ICAPS 2018](https://arxiv.org/abs/1709.06196) | Continuous observations make naive search-tree widening collapse beliefs. A weighted-particle online search is a relevant strong comparator when registered masks replace the discrete centroid alphabet. |
| [Ni et al., Recurrent Model-Free RL Can Be a Strong Baseline for Many POMDPs, ICML 2022](https://proceedings.mlr.press/v162/ni22a.html) | Recurrent policy implementation, history handling and matched controls matter. The tested recurrent learner receives an explicit particle belief, so its comparison measures incremental memory beyond public state summaries. |
| [Kumar et al., Conservative Q-Learning, NeurIPS 2020](https://proceedings.neurips.cc/paper/2020/hash/0d2b2061826a5df3221116a5085a6052-Abstract.html) | CQL addresses unsupported actions in offline logs. The old and current CQL policies use fixed replay. The conservatism in its value objective does not control false positive anatomy directly. |
| [VesNet-RL](https://arxiv.org/abs/2205.06676) | Connects policies trained on simulated binary vascular images to segmented ultrasound for navigation to a vessel longitudinal plane. Provides a precedent for mask-driven policy transfer. |
| [Morales et al., BIFURC, IROS 2024](https://arxiv.org/abs/2409.06817) | Identifies a bifurcation from ultrasound-derived vascular trajectories and evaluates on a phantom and live pigs. The relevant comparison is identifying the connection from recorded evidence before adding adaptive scan selection. |

For two equiprobable hidden structures that require incompatible final decisions, the maximum correct decision probability after following a given public policy is `(1 + TV(P0, P1)) / 2`, where `P0` and `P1` are its full observable history laws. Additional required steps such as feasible fresh acquisition can only reduce correct completion relative to this bound. This is the standard binary testing limit applied to the project. It motivates measuring whether a new scan reveals physical connectivity before fitting another policy. [Derivation and feasibility analysis](theory/MINIMAL_DESIGN.md)
