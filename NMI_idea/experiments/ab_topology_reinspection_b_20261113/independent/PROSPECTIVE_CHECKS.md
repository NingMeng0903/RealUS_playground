# Independent prospective audit checks

The intervention is graph-conditioned continuation after a common MPC prescan. A fair comparison must permit all policies to use the same information and physical opportunities. The tests below establish what each policy actually received, executed and accomplished.

| Property | Check |
|---|---|
| Common executed prescan | Rebuild the initial state from its public prior, replay MPC at each prescan decision, match action legality, packet hashes and exact exit state. Verify the traces contain multiple assimilations and a public route or score response to observations. Report policy decisions that would be identical in a fixed-route replay as a limitation. |
| Hidden graph | Verify the motion grid, action schema, initial public state, task semantics and prior construction are independent of case topology, geometry, noise tape and physical return IDs. Treat the case seed as evaluator input only. Permute hidden edge IDs and candidate order on otherwise identical episodes. |
| Same acquisition opportunities | Compare action masks and common terminal acceptance on equal public histories. Confirm belief search and MPC both include every publicly feasible sensing, scanning, stop and declaration action available to B. Distinguish exact full-horizon search, finite approximations and sampled heuristics. |
| Packet and clock parity | Replay every common physical pose and arrival time on the same latent case/noise tape. Confirm packets do not contain labels, source ordering, stable simulator IDs or implicit topology hints that would not be measured. Check deterministic physical-time/time-bin/pose indexing and packet cardinality. |
| Identity | Independently reconstruct selected candidates and their labels. At least two new observations must belong to the same qualifying connected daughter and cover the prescribed downstream interval with no invalid gap. A nonempty image, high graph posterior or a correct graph with an incidental new return alone cannot pass. A false connection and a negative-case false positive should count as wrong. |
| Stopping | Trace all policy exits to the public acceptance rule, documented abstention or common cap. A policy may fail gracefully, but repeated false/negative declarations must remain in the fixed denominator. |
| Cost | Accumulate actual edge costs, clock/elapsed time, rotation, captures and any predeclared separate CPU ledger. Recompute common and continuation costs individually and then sum. Confirm no nominal or end-to-end asymmetry. Test the predeclared realized-cost contrasts separately from caps and the same fixed action budget. |
| Learning | Recheck train/dev/heldout keys, pretest model/score selection, CQL behavior coverage and legality masks, recurrent state reset and prescan warmup. Check whether recurrent PPO saw outcome labels only in simulation rewards, and whether privileged features appear anywhere in online scoring. Report seed-wise curves and baseline competence rather than treating a weak pilot as a strong negative. |
| Statistics | Recompute numerators, effect signs, overlap and exact pairing from rows. Group any multiple tapes by latent case. Keep all assigned cases, including zero-information and infeasible stops. Test mechanism under fresh seeds and stress-family changes. Confirmative claims require prospectively frozen gates and sufficient independent sample sizes. |
