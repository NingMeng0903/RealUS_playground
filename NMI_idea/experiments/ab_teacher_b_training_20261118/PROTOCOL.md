# Teacher data for second-stage B

This paired synthetic study compares the training value of three ways of nominating probe examples. The shared executable library combines the previous requests with all eight verified request IDs selected across the three sources in the generator pilot. Each new ID is rendered by the already fitted ProDMP conditional on the current position and velocity and checked for feasibility. The library comprises these requests and one shared set of motion weights. Duplicate nominal paths can map to a common executable action. Every arm uses the same receding-horizon controller with the expanded menu available at recovery decisions, 10 Hz image-packet feedback, evidence ledger, stopping rule and physical limits.

## Frozen comparison

- Start with the complete historical training data for the frozen ordinary-augmentation B. The base includes 392 task-state rows on 312 scene seeds, yielding 8,122 feature vectors and six stored paired outcomes per candidate. Use the same 457 inputs and six histogram gradient boosting regressors, with the original anatomy-window calibration and decision rule.
- Generate fresh training checkpoints from a shared MPC prefix in the connection and no-fork tasks under ordinary and burst-loss regimes. At each checkpoint, every source nominates four distinct non-incumbent requests from the same feasible pool. The pool uses the newly added requests when at least four distinct variants are feasible and the full expanded menu otherwise.
- The geometric teacher nominates based on peak simulated target visibility with current true geometry. The evidence teacher uses the prior pilot's observation-dependent score from the public posterior. Structured random draws from the same pool. The geometry teacher's private scene is used for nomination alone.
- Execute each nomination and the common MPC incumbent in eight paired, independently seeded counterfactual continuations. Sample the latent hypothesis from the public posterior and nuisance from the specified stress distribution. Predict possible further loss from the observed empty packets and draw the future duration independently. The evidence teacher uses different samples for nomination and labeling. Use the virtual record to condition historical witnesses on the sampled latent. Retain all outcomes, including completion failure, transient and final misidentification and executed costs.
- Fit one model per teacher data source, using the same old feature matrix plus equal numbers of new task-action rows. Each new label is the mean paired change relative to the MPC incumbent in completion, final and interim identity errors, distance, turn and time. Include the common zero-delta incumbent once on each root in each training set. Freeze weights and inputs before confirmation.
- Choose the best single recheck request per family on an independent qualification split. Each fixed request falls back to MPC when infeasible. Score its average over all qualification cases including this fallback. Freeze the reference before the holdout. Fresh held-out runs compare fixed recheck, full MPC, original frozen B and the three retrained B variants. All six arms share the expanded menu at the handoff. When B selects an initial probe, it then hands control back to the same full MPC.

## Endpoints and analysis

The intended split has 128 training states, 32 qualification cases and 128 holdout cases, balanced across both task families and loss conditions. Use independent seed namespaces in the range 74 million. Each holdout case uses the same physical initial state and eight matched future disturbances across arms. No qualification or holdout labels enter training.

Report correct scan completion with newly retained correctly identified imagery, transient and terminal error trials, executed distance, turn and time, with strict centering reported separately. Planner CPU excludes the common pre-scan and does not enter the simulated scan clock. Report pooled and family results with scene-paired bootstrap intervals, giving particular attention to the contrast between each directed teacher and the equal-dose random control.

This design measures the effect of candidate nomination for training B at a fixed augmentation dose. It preserves the ProDMP coefficients that already generate the eight new motions. It uses a model-based predictive supervisor with factorized stress nuisance and threshold-based loss continuation. Its new cases are independent simulations from the existing leg-atlas task families at a fixed knee angle.
