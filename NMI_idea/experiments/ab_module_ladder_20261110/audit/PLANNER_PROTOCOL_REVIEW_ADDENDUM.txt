a0_identity robot context, initial uniform belief, no public history and R=60.
It checked 7 root candidates x 32 model blocks = 224 hypothetical public branches.
Real finite static endpoint search produced 74 memoized robot witness queries;
there were zero native calls and no selected actual patient world.

did NOT call Planner.decide, terminal, block_posterior or correct_given_public.
It independently formed the likelihood/target-source masses for every h and
source, summed those unnormalized masses before choosing a terminal action,
and applied the censored RMT and identical finite witness transition/candidate
specification. The same 32 sampled public observations define both kernels.

Result: every root value agrees within 7.105427357601002e-15. The selected action
[0,-.0136952,0] and value 50.0822751322156 agree exactly; both select a branch
option. All 224 sampled blocks in this particular initial state were non-stops;
public-stop target association is additionally covered by the initial audit's
nontrivial ambiguous-source probability fixture. Evidence and full source/robot
hashes: sampled_backup_check.json/.log. This is a stronger correctness check than
the separate coarse-operator toy, but it certifies only this sampled kernel/state.

What is now implemented, and what remains approximate
- dIRD actually participates in terminal task-value ties within 1e-9. Its score
  still cannot replace the common real endpoint check or alter anatomical
  hypotheses. Invocation or tie preference alone is not demonstrated proxy gain;
  the separately controlled query-budget retrieval experiment addresses that.
- B_no_future_cap is now correctly described as removing BOTH future endpoint
  availability and the joint-displacement time estimate. Current hard checks
  remain shared. Results must not be attributed to availability alone.
- 32 quantile samples cover each member once under a uniform 32-member prior
  (twice under the 16-member DEV prior used here), but noise integration remains
  approximate. Future candidates use compact posterior templates/expected
  centering; all actual A/B decisions retain the same full continuous permission
  family. This is a forecast approximation, not an exact sufficient compression
  or a proof the forecast and real future candidate families coincide.
- Measured online compute is charged by the actor. Future compute is not known
  to the backup, so it remains an approximation to total online cost. Accounting
  should include charged terminal planning work that ends before an acquisition;
  do not derive the whole cost decomposition solely from completed-frame events.
- Real URDF/FK/self-collision-checked q_kin witnesses are static planning state,
  not actual native q_out or a certified path/contact/dynamic state. A failed
  finite search is not physical infeasibility. The separate native evidence is
  not elevated to full image/force/SMPL-X closed-loop execution.
