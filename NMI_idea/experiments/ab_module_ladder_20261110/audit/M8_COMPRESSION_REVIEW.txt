Compression conclusions justified by current evidence
- The code builds M[(a,y,j),h]=L[h,a,y]*R[h,j] from the sealed likelihood/risk
  arrays. Every latent contributes before minimization; the direct risk b@R
  stays exact. This is a standard finite Bellman/linear-operator construction,
  not a new inference principle or a recursive sufficient-state theorem.
- The 4275x64 matrix has reported numerical rank64. Requested rank32 is a lossy
  unconstrained SVD, with signed entries retained honestly. It changes the
  complete direct/probe policy on34/96 saved belief tests, has future-value
  sup error .9698989, and produces3611 negative Xi entries (minimum about-.3946).
  This is a negative compression result. Signed approximations must not be
  described as probabilities, calibrated risks or nonnegative posteriors.
- Rank64 recovers values to roughly2.2e-13 and the global policy0/96 differences.
  It does not reduce dimension: full matrix bytes2,188,800 versus rank64 factor
  bytes2,221,568, before the unchanged exact-direct-risk storage. Thus exact
  recovery is a useful implementation check, not an efficient compression win.
- Raw conditional argmin changes include ties: rank64 has33/96 raw best-probe
  changes but0 substantive non-tie changes and0 global policy changes. The
  saved tolerance1e-10 correctly separates these; do not interpret numerical
  tie-breaking as a theoretical counterexample or policy gain.
- The simplex-uniform propagation bound
    max_a sum_y max_j max_h |M_r[(a,y,j),h]-M[(a,y,j),h]|
  is mathematically valid for b in the simplex and the SAME terminal action set.
  It is conservative: at rank32 it is233.1714, larger than the entire60-unit
  terminal-risk range. Such a vacuous bound certifies neither useful regret
  control nor action preservation. Descriptive RMSE cannot replace this bound.
- These are96 belief weights (64 existing aliases +32 Dirichlet draws), not96
  independently generated patients. Exact frozen c=.5 chooses95 direct and1
  probe. All64 aliases remain direct. Earlier28/32 alias disagreements refer
  ONLY to best probe conditional on probing; full alias policy changes remain
  0/32. The earlier audit independently recomputed this complete-policy count.
