POSTHOC ORACLE INPUT-CONTRACT CORRECTION
=========================================
Date: 2026-11-10

Status and exclusion
--------------------
This is a posthoc correction of the *public hypothesis representation* used
by the already completed truth-leaked oracle diagnostic.  The original
``run_20261110`` directory and its RESULTS.json remain immutable and are not
re-run or overwritten.  The corrected run is a separate diagnostic output
named ``run_corrected_parameterization_20261110``.  Both runs carry the
uppercase ``ORACLE_LEAKED_TRUTH`` marker and are excluded from the legal
finite-prior A/B experiment and every formal summary.

Reason for correction
---------------------
The shifted private GT is deliberately built with ``modes[:,1] += .4`` to
encode the +0.10 physical slope shift.  ``template_candidates`` requires
the discrete public mode label ``modes[:,1]`` to be exactly -1 or +1.  Passing
the shifted ``-.6/+1.4`` labels directly to the oracle planner therefore
emptied the matching template family.  This is an input-contract error in
the oracle hypothesis, not a physical change to the shifted GT.

Frozen worlds and physical-equivalence reparameterization
----------------------------------------------------------
Regenerate exactly the same private worlds as the sealed legal and original
oracle runs: ``sample_worlds(seed=720380, n=8, split='test')`` for ``iid``
and the existing copied shifted worlds (registration y +0.008 m and
``modes[:,1] += .4``).  Verify the private GT digests against the sealed legal
RESULTS before any episode.  The private GT passed to rendering/audit is
always this original shifted object; it is never replaced by the corrected
hypothesis.

Only the planner particle for a shifted case is reparameterized.  For each
source, let ``m_s`` be the shifted slope label and ``m_c = sign(m_s)``.  Set
``delta = m_s - m_c``, restore ``modes[:,1] = m_c``, and add
``delta * .25 * CONTROL_X`` to that source's five ``y_controls``.  Keep
registration, all other modes, z controls, depths and nuisances unchanged,
then rebuild with ``env._world``.  Because ``_points`` uses
``modes[:,1] * .25 * X`` and the added controls are exactly linear in X, the
canonical hypothesis and original shifted GT have the same source points.
For iid cases the original world is already canonical and is used unchanged.

Before any episode, assert for all 16 cases that:

* private GT hashes match the sealed legal run (and the original oracle run
  is still byte-hash unchanged);
* source points agree to absolute tolerance 1e-14;
* a fixed 9 x 9 x 7 pose grid gives elementwise-equivalent prediction
  ``means`` (atol 1e-8, rtol 1e-10), ``p_source`` (atol 1e-12, rtol 0), and
  the remaining deterministic prediction fields; maximum absolute residuals
  are saved;
* canonical public hypothesis labels are exactly +/-1 and
  ``template_candidates`` is nonempty at the episode seed pose.

The tolerances only absorb floating point ordering in segment clipping; the
source-point identity is checked at 1e-14 and all residuals are retained.
