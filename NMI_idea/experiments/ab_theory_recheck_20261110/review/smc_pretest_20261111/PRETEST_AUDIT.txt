Target and release boundaries
For a persistent patient theta the intended stage density is proportional to
p0(theta) L_old(theta) L_new(theta)^beta. Five frame likelihoods multiply
within each theta; old data enter every MH target once. Symmetric proposals
permit the ordinary target ratio. A target-invariant move may retain incoming
importance weights; uniformity is only required after resampling. Beta=1 must
actually be reached before committing evidence and its normalizer.

The sampled bridge can fail even when the continuous prior supports the true
world. Resampling cannot create unsupported worlds; local MH need not cross
hard likelihood barriers within a bounded budget. CESS and post-resampling ESS
are not posterior coverage certificates. This distinction is essential here.

Matched-history runner review
The current runner uses the same initial 128 prior draws; fixed32 is the first
32. All methods receive the same five survey and three public-anchor blocks.
The anchor reads visible/contact/identity/u plus actual pose, with a fixed
zero fallback. Public line fitting is also available to the terminal selector.
Neither uses the hidden target curve. Prefix5 and prefix8 terminal/prediction
frames are diagnostic forks and never enter the posterior/history.

The four previously requested runner fixes are present: approval verifies
running files as well as the approval manifest; public-line evaluation obeys
the same 60s deadline; valid-only predictive NLL exposes scored/invalid counts;
predictive weights use exact zero support instead of a 1e-300 likelihood floor.
Shared anchor compute is charged to every method. A failed update records its
diagnostics before the explicit failure and prevents a false full-history
posterior. The predictive NLL is per-frame marginal heldout density, not a
joint five-frame density; the distinction must remain in any report.

Wall inference/selection and modeled DMP motion/observation times are included.
These motion costs are not native robot execution costs. Same permission does
not mean identical terminal poses or identical terminal images when poses
differ. Causal isolation here is an inspected data/API contract, not a separate
OS security boundary. A final release must freeze all runtime choices,
including backend, and every relevant dependency; the current audit does not
approve an arbitrary later manifest or a new proposal module.

Bounded support-recovery advice
A linear likelihood bridge g_beta=(1-beta)+beta*exp(logL-s) can preserve the
same final target if incremental weights use log g_new-log g_old, MH uses
prior+old-history+log g_beta, and the evidence scale s is restored. It alone
does not solve all-zero particle support: CESS may stay N until the singular
endpoint. A bounded support-finding proposal is still needed.

An observation-conditioned proposal is lawful if its complete normalized
continuous/discrete density q is evaluated, the public source/target mixture
is retained, and weights are p0*L_full/q. Fresh full-history importance weights
must not also multiply old posterior weights. A positive prior mixture can
protect model support but cannot guarantee finite-budget effective coverage.
No unweighted translation to an observed detection or silent likelihood
softening is acceptable. This is engineering/statistics, not the project's
new theory. The pending module has not been audited in this report.
