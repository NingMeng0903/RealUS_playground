Public-history informed proposal DEV record
============================================

Scope
-----
This is a DEV-only retrospective comparison.  It used sample_prior(720901,
128) and the first sample_worlds(720902, 1) object, with exact shared-history
keys (0,'iid','dev') and (0,'shifted','dev').  Prefixes 5 and 8 were evaluated
against the fixed128 baseline.  No 720913 data were opened.  Predictive and
terminal fields below are diagnostic forks and never enter q or the importance
weights.

Informed proposal configuration
-------------------------------
epsilon=.1, 16 modes, 8 public-only association patterns (seed 720907),
N=128, full-history log likelihood, normalized 30D q density, and one
importance update per prefix.  All four informed cases reached a finite
importance result, but every raw ESS was approximately 1.0.  This is a real
weight-degeneracy limitation, not a success claim.

The informed proposal selected a retrospectively audit-quality terminal pose
in the shifted prefixes, but its public stop was false and the importance
weights collapsed.  The shifted prefix-8 predictive score was worse than
fixed128; the proposal therefore demonstrates a normalized, public-only
support-recovery mechanism, not a validated A/B performance improvement.

The implementation records finite likelihood count, raw ESS, maximum weight,
evidence estimate, component/pattern hashes, and zero-support failure.  It
does not floor likelihoods, discard a block, multiply old weights, or use
private truth.
