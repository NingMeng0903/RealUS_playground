DEV-only continuous SMC smoke evidence
========================================

This is a local geometric smoke bench, not a closed-loop result and not a
held-out performance claim.  It uses only sample_prior(720901, 128) and
sample_worlds(720902, 1), with eight MH sweeps per tempering stage.

Single block, pose [0, 0, 0]
---------------------------
Both DEV worlds generated five invisible public frames.  Each update reached
beta=1 in one stage, retained 128 unique geometries, and ended with raw ESS
101.711 (acceptance 0.872) for the first world and 101.711 (0.887) for the
second.  The block log evidence was -0.2325746832 in both runs.
