Registered protocol — local action-response query identifiability
===============================================================

Status
------
This file is written before the numerical run and is not changed after the
results are obtained.  The experiment is an abstract local linear mechanism
test only.  It is not a claim of complete A learning success, real ultrasound
validity, or superiority over a production controller.  It tests whether the
same public local action-response observations identify the future query that
an A-type response model is asked to predict.

Question and registered conclusion to test
-------------------------------------------
For a local response y = c + J a + epsilon, the past action design must excite
every parameter direction used by a future query.  We test the exact condition
ker(F) subseteq ker(G).  The no-excitation design intentionally leaves the
second action column unobserved; the completed design adds one orthogonal
action.  No parameter, threshold, or result is tuned after inspecting output.

Model and normalization
-----------------------
* y in R^2 is normalized by (2 mm, 2 degrees); a in R^2 is normalized by
  (1 mm, 0.05 rad).  All reported normalized errors can therefore be mapped
  back componentwise to the physical tolerances.
* y = c + J a + epsilon, epsilon ~ N(0, 0.02^2 I_2), independently per
  observation.
* J = R(phi) diag(g1,g2) R(psi), phi,psi ~ Uniform[-0.8,0.8] and
  g1,g2 ~ Uniform[0.7,1.3].  c ~ Uniform[-10,10]^2.
* The public regression parameter is theta =
  (c0,c1,J00,J01,J10,J11,zeta0,...,zeta5), dimension 12.  The six nuisance
  coordinates are sampled Uniform[-1,1], are unobserved and have no term in
  y; they make full-theta identification impossible without changing any task
  query.
* Main design: seed 720940, 512 independent subjects.  Each subject has the
  same number (four) of public raw (y,a) observations.  The learner receives
  only those pairs and never reads J, c, or nuisance values.
* Gaussian noises and target draws use the registered seed.  Paired random
  numbers are shared between designs where dimensions agree (common random
  numbers), and this is recorded in the raw arrays.

Fixed observation designs
-------------------------
No excitation:       (0,0), (-1,0), (1,0), (0.5,0)
Completed excitation: (0,0), (-1,0), (1,0), (0,1)

The learner uses minimum-norm least squares theta_hat = F^+ y (equivalent to
batch RLS in the vanishing-ridge limit), with c and J read from theta_hat.
The fixed baseline sets J_hat = I and estimates only the offset when needed.
No observations are added after querying; all query models are frozen after
the four registered observations.

Design and query matrices
-------------------------
For each action a=(a0,a1), the two rows of F have nonzero entries
  y0: c0=1, J00=a0, J01=a1;
  y1: c1=1, J10=a0, J11=a1.
The six nuisance columns are zero.  A future increment query delta a has G
rows with the corresponding J entries and zero offset/nuisance entries, so
Delta y = G theta = J delta a.

Registered future queries
-------------------------
* translation: delta a=(0.5,0)
* rotation:    delta a=(0,0.5)
* combined untrained query: delta a=(0.35,-0.40)

The first two queries probe the exact nullspace claim.  The combined query is
fixed before running and is not fed back to the learner.

Required checks and metrics
---------------------------
1. Compute rank(F), rank(G P_F), rank(G(I-P_F)), where P_F=F^+F, and the
   residual ||G-G P_F||_F.  Verify numerically that translation is identifiable
   in both designs, rotation only in the completed design, and the full theta
   remains rank-deficient.  This is the operational ker(F) subseteq ker(G)
   check; tolerance is 1e-10 for the deterministic matrices.
2. On all 512 subjects, report mean/RMSE/median/p95/L_inf maximum prediction
   error for translation, rotation, and combined queries for LS and J=I.
   Retain every subject; do not filter difficult cases.
3. Optional registered task-increment controller: t ~ Uniform[-0.3,0.3]^2,
   a = pinv(J_hat)t clipped componentwise to [-2,2].  The learner sees t and
   its four observations only.  The scorer alone evaluates the true J a.
   Success is fixed as ||t-J a||_infinity <= 0.08.  Report all 512 cases,
   clipping and success; do not tune this threshold.
4. Validate noise covariance with 4096 independent noise replicates at one
   fixed allowed theta/c per design/query.  Compare the centered empirical
   covariance of query estimation noise to
   sigma^2 G (F^T F)^+ G^T.  For an unidentifiable query, explicitly separate
   this estimator-noise covariance from the missing-direction bias; the
   zero reported noise variance does not imply the query is known.
5. Construct an alias pair J_plus=diag(1,0.8), J_minus=diag(1,1.2), same c
   and nuisance.  They are both allowed model instances, have identical
   noiseless no-excitation public observations (and identical noisy public
   distributions under the same independent noise law), but their rotation
   query (0,0.5) differs by 0.2 in the second output.  Completed excitation
   distinguishes them.
6. Reuse each frozen fitted model on the registered future queries without
   refitting.  An independent test script reconstructs F/G, checks ranks and
   alias equality, and verifies the LS predictions against an explicit
   row-wise solve.

Interpretation guardrails
-------------------------
The expected mechanism is failure of no-excitation rotation identification
and improvement after the fourth orthogonal action.  If RLS with the right
excitation is equally accurate, that is the result: this experiment does not
justify a neural-network requirement or claim B is superior to RLS.  A
positive result here only establishes a necessary query-identifiability
condition for a local response module; it does not establish cross-person
transfer, belief update quality, executable robot motion, dIRD global
continuity, or real ultrasound performance.
