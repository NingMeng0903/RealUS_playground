What the earlier failures did and did not test
Earlier A was analytic geometry, not newly learned acoustic/response skills.
Continuous GT0/8 used a32-world fixed support, so new anatomy could never move
outside that bank. B was an approximate two-step finite-belief planner and did
not beat the strong analytic A. Neither score justifies declaring the user's
conditional-response idea false or B superior. Prior physical/anatomy data
remain distinct from controller-visible evidence.

Mechanism1: action-query identifiability (A)
The anatomy/response parameter need not be globally identifiable if all future
task-relevant response queries are identifiable. In a declared local linear
model y=F theta+noise and response query G theta, ker(F) subset ker(G) is the
appropriate noiseless criterion. Location nuisance can cancel in relative
responses, but actual target registration remains relevant to acquisition.
Equal-number translation-only versus translation+yaw probes test the predicted
failure boundary. Use an adaptive least-squares/RLS baseline, not only a fixed
wrong Jacobian. Small mathematical examples validate mechanism, not clinical
ultrasound or neural-network necessity. Root-owned worker protocol gives512
fixed simulated subjects and a frozen noisy response task.

New inference is an engineering/statistical repair, not claimed new theory.

Mechanism3: observation is useful only if it changes affordable decisions (B)
Independent review derives exact binary/Gaussian thresholds and negative
controls: prior already decisive, noninformative observation, same optimal
continuation for every observation, excessive acquisition/compute cost, and
uniformly easy robot execution. A cheaper threshold-probe or adaptive RLS is a
required comparator where applicable. A small exact Bellman result cannot be
reported as a novel general VOI/POMDP theorem.

Only after mechanism2 works should repaired beliefs enter the same A/B planner.
Keep strong continuous A, task-myopic A, entropy, equal-horizon fixed continuation
and capability-aware B. Remaining action/time resources and all online compute
must be charged. Any new multi-rate sensing/decision budget is a separately
registered study, not a retrospective edit to old6-action/60s results.
Future-model observations never enter actual belief. If a learned predictive
response model lacks a hypothesis-conditioned likelihood, it must not silently
replace the likelihood used for posterior updates.

Theory/novelty decision
Shared local response must prove useful under heldout tasks/contexts, not merely
fit labels. B must explain and demonstrate a regime of future-decision value,
plus its zero-benefit regime. Functional identifiability, Kalman/SMC/Bellman
identities and generic compression bounds are existing tools; a new paper needs
anatomy/contact/task structure, a computational method and independent evidence.
e3nn, EM and complex primitives remain optional until an actual bottleneck and
increment justify them. No score/journal ranking substitutes for these tests.
