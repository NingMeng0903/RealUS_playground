# 连续探查与 MPC 配对

主路线沿用旧版 MPC 的离散候选、贝叶斯关联、角度打分、一次前视、站末采样与运动成本。探查作为额外动作执行，在原站位、原角度结束，再继续主路线。离散探查将同一控制命令量化到原扫描网格，沿接触面向目标往返。连续探查在同一几何环境中执行 ProDMP。两种探查都使用 $0.1\,\mathrm{s}$ 的模拟采样周期、相同物理上限、同一个按绝对时钟索引的随机带，以及相同的未标记回波和质量通道。

## 连续动作

一次命令给出三个 $[-1,1]$ 的控制值，分别指定角向位移、轴向位移和基函数形状。单位幅值对应 $2.5$ 个角向网格间隔和 $2$ 个材料站间隔。材料站距为 $5\,\mathrm{mm}$，SMPL-X 形状变换后的轴向实际距离随形状变化。角向一格对应 $15^\circ$。当原幅度超过接触或预算限制时，依次检查 $0.75$、$0.5$、$0.25$ 倍的可执行幅度。回放可读取 `MotionResult.applied_fraction`。

每一段轨迹复用原项目的临界阻尼 ProDMP 积分基，施加当前位置、当前速度、目标位置和末端零速度约束。形状控制作用于基函数端点约束的零空间。在每个采样帧之后，可根据当前匿名回波、贝叶斯概率和质量更新剩余段的权重。更新保留当前位置、当前速度和既定端点。只有剩余计划满足接触和距离约束时才应用修正。可通过 `feedback=False` 固定原始积分基轨迹，通过 `feedback_updates` 记录有效修正次数。

每个探查时钟间隔用五个图表采样位置估计皮面行程并检查接触。本实验按每个采样区间限制实际运动弧长，速度上限为 $43\,\mathrm{mm/s}$。不满足预算的动作不更改节点、时间或帧档案。轨迹列依次为时钟、连续站位索引、连续角向索引、该间隔行程和累计探查行程。

原 MPC 站位是离散静止锚点。探查从该站位的零速度状态开始，末端返回零速度。仿真沿用主扫描的站末离散耗时，未单列额外的机器人停稳过程。

## 回波与解剖输入

CT 支持区间从中性坐标 $-480$ 到 $-560\,\mathrm{mm}$，覆盖 17 个原始采样站。形变后的皮面接触由连续截面半径和中心计算，CT 和 atlas 的遮挡由人口骨占据场在实际声束位置重新求值。Blender 使用原注册接触图和骨三角网格，亚网格姿态处重新计算切片交点和逐回波射线遮挡。仅在输入拓扑给出相邻站连边时插值中心。连续接触面来自截面插值，平台验证限定为合成超声和运动学仿真。

贝叶斯模型的血管候选来自三套训练参考 atlas。CT 和 Blender 的真值中心用于生成回波及评估。反馈接口使用最新匿名回波的横向坐标、质量和后验概率。样本角色仍存在独立评估通道，用于验证扫描是否获取正确血管。验证脚本置换该通道，检查公开特征和闭环轨迹逐项相同。

已知相邻边约束用于成像真值。贝叶斯模型沿用允许轴向偏移的旧候选结构，亚网格候选在有限的相邻先验中心之间插值。该候选投影不会写入解剖图或生成待识别回波。

## 复现

```bash
python outputs/leg_scan_study/motion_checks.py \
  --ct-pack outputs/leg_scan_study/topology/ct_geometry.npz \
  --legacy '/media/camp/PEI_T7/1_team meeting/atlas_ppt_build/assets/blender_topology_holdout/geometry.npz' \
  --out outputs/leg_scan_study/diagnostics/motion_checks.json
```

脚本对照了五条 Blender 路线的 266 个原 MPC 锚点，验证同起终状态的形状可辨识性、闭环对匿名回波扰动的响应、评估标签置换不变性、部分采样姿态处于亚网格、探查端点回归、每时钟一帧和物理预算。
