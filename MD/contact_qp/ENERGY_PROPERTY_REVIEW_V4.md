## 1. 功率、坐标与假设

环境作用于探头的 wrench 为 W，实际 TCP twist 为 Va；均为 SI 单位、同一附着 TCP 原点、同一工具坐标分量。输入功率为 `p=WᵀVa`，机器人输出功率为 `-p`。六个分量先求和，再处理功的正负；不能逐轴正部相加，也不能重复扣 `F0*vn`。

刚体参考点/坐标变换满足 `V'=A V`、`W'=A^{-T}W`，故 `W'ᵀV'=WᵀV`。任务用的正压缩力及控制力矩不自动等于物理 W 的相应分量。补偿残差的 sign、sensor/link7/TCP 变换、重力或动态补偿误差均属于物理端口绑定的一部分。

在一次完整执行区间 `[tk,tk+h]`，令最终经过 IK/payload 修订的命令模型为常量 V，并声明：

1. `|W(tk+τ)-Wm| ≤ ε + L τ`，`0≤τ≤h`，ε、L 按分量非负。
2. `Va=V+e`，`|e|≤η`，η 覆盖整个区间内的真实执行偏差，包含采样保持、IK 松弛、异步开始/停止及旧命令持续造成的差异。
3. `r=Pc Va`，`D(t)=Σj d_j r_j²`，d≥0；对于 d_j>0，有真实整段 `|r_j|≤rbar_j`。
4. 命令执行/停止的真实时段不超出该界的有效范围；发送时源年龄与发布延迟已计入 ε。不能用当前观测到的误差替代未来整段 η。

这些是定理的明确模型类。理想执行取 η=0；不需要组织精确刚度或声学预测模型。现实装置是否满足给定 ε、L、η、停止时限和速度界，是另一个需要测量/工程依据的命题。

## 2. 单拍共享能量行及每个前缀的证明

令 `q=|Pc|η`、`a=d⊙rbar`。由于 `|Pc Va|≤|Pc V|+q`，对所有 d_j>0，在同一个 QP 中施加

`|Pc_j V| ≤ rbar_j-q_j`。

右端为负意味着任务/能量不可行；不能用零命令伪装成功。d_j=0 不为该耗散项额外限速。

由分量三角不等式及实际速度界，

`WᵀVa ≥ WmᵀV -(ε+Lτ)ᵀ|V| -( |Wm|+ε+Lτ )ᵀη`，

`D(t) ≤ aᵀ(|Pc V|+q)`。

定义

`A = WmᵀV - εᵀ|V| -( |Wm|+ε )ᵀη - aᵀ(|Pc V|+q)`，

`B = Lᵀ(|V|+η) ≥ 0`，`G(τ)=Aτ-Bτ²/2`。

逐项积分得到完整六维供能减耗散的下界：

**`∫[tk,tk+τ] (WᵀVa-D)dt ≥ G(τ)`。**

因此 QP 的一条共享能量行就是 `G(h)≥-βS`，`0<β≤1`，即现有 `PortEnergyConstraint.lower_power_w(V) ≥ -βS/h`。绝对值用 epigraph 变量实现；物理决策仍只有 `[vn,ω,α]`。最终值须用实际 V 重算绝对值和发布时刻误差，不能依赖辅助变量的非唯一取值。

G 为凹二次函数，G(0)=0。对任何 `τ∈[0,h]`，凹性给出

`S+G(τ) ≥ (1-τ/h)S +(τ/h)(S+G(h)) ≥ (1-βτ/h)S ≥0`。

这证明的是 **整拍每个前缀** 的预算非负，不只检查终点。源已老化 Δ 秒时，必须先换成 `ε'=ε+LΔ`，并保留完整后续 h；不能缩短未来保持时长来掩盖源年龄。

## 3. 同一账本的累计耗散证明

先看完整执行区间与结算边界一致的条件版本。令 `Ck` 是该区间总输出功加耗散的上界：

`Ck ≥ ∫[tk,tk+1] (-WᵀVa+D)dt`。

使用附件的保守模型更新时取 `Ck=-G(h)`，并在本区间完成之后更新同一账本：

`Snext=min(Smax,S-Ck)`。

由上节，`Snext≥(1-β)S≥0`。令 `Qdump=max(0,S-Ck-Smax)≥0`，则

`Snext-S=-Ck-Qdump ≤ ∫(WᵀVa-D)dt`。

累加，并用最终 S≥0，得到

**`∫[0,T] WᵀVa dt ≥ -S0 + ∫[0,T] D(t)dt`。**

上限泄放只使不等式更保守；下限强行截断会破坏它。D=0 时退化为普通端口能量不等式。若环境被动、其非负储能 U 满足 `ΔU≤-∫WᵀVa`，则 `∫D≤S0+U0`。在 d 正定于所讨论接触速度、信号具有必要一致连续性等附加条件下，才能进一步推导接触速度趋零。不能由此宣称力误差、声窗误差收敛，或任意主动人体都被动。

异步实测结算可使用任意不重叠的真实时间分段，但每段扣账仍须是该段 `-WᵀVa+D` 的上界，且所有未结区间/停止暴露有足额预留，账本始终非负。上界结算估计可能比原候选预算更保守；**仅“两个量各自都是上界”并不能保证任意替换结算后账本仍非负。** 若采用另一结算公式，必须核对其与预留的相容性；或在两个已证明、覆盖同一已完成区间的上界中取较小者。不能提前使用未来回能，也不能因模型预算存在就强行抹掉超支。

当前 MONITOR 接口没有宣称上述真实上界成立。因此它正确记录估计账本及负余额，不把测试通过或 `physical_w_checked=true` 当作物理证明。

## 4. 预留与停止条件不能遗漏

预留不是第二个 tank。普通可用额为已结余额减所有尚存负债及停止保留额。拒发只能撤销已证未曝光的新候选；旧命令、部分发送、缺测区间的负债不能退款。重复或重叠物理时段只结算一次。

严格异步证明还要求：部分时间段结算后，剩余预留必须覆盖剩余真实暴露。`max(0,-G(h))/h` 只是整拍平均预算，**不是瞬时功率上界**；不能仅凭它按时间比例退款来证明任意中途的剩余暴露足额。已有 RuntimeEnergy 为 command-model/MONITOR，不能把这种平均预留升级为异步物理认证。

不需要修改原 IK 才能陈述足够的停止条件。例如若从停止请求起最多持续 Tstop，真实完整六维速度满足 `|Va|≤νmax`，并有对应 W 误差/变化率界，则以下是一个保守的停止输出功加耗散预算：

`Estop ≥ Tstop (|Wm|+ε)ᵀνmax + Tstop² Lᵀνmax/2 + Tstop Σd_j rbar_j²`。

νmax 必须覆盖臂、轨异步停下及旧命令，不是只界定净候选 V。可由声明工作域内的 Jacobian 与各设备实际速度界构造；是否适用仍需真实工程依据。没有这些界时保留原机械停止并报告 MONITOR，不能宣称零命令能立即消除实际功。

## 5. 实测区间实现与估计限度

目前新接口以连续 fresh UDP 的 W/arm 实测端点为主区间，raw rail 必须在两端有实际样本夹持，并按 rail 采样断点细分。禁止外推、跨缺测/版本混用，source 重复不增加观测。每段由 measured q 的差和 `J(qmid)` 得到工具分量速度估计；W 的端点也在同一附着 TCP 的 body 分量中插值。frame/body 参数化与共同区间有效，不代表有限差分/Jacobian 中点近似已具有确定误差界。

`observe_interval` 直接结算完整段，不把区间平均速度再当作中点瞬时样本二次拼接。旧 tracker 的 SDK/rail 异步诊断和 `min(midpoints)` 不参与这一结算。控制命令是否准备、拒发或提交不改变已经存在的测量事实。

现有端点输出功估计加声明 rate 项，只有在端点误差及整段功率变化界成立时才是严格上界。MONITOR 的

`Dhat=Δt Σd_j(Pc Vmean)_j²`

也只是估计：往返运动可能 Vmean=0 而真实 ∫D>0。条件上界可用 `Δt Σd_j rbar_j²`，或对已界实际速度轨迹积分。不能把 mean-D 标签改成 upper-bound。未知采样硬件时间偏差、补偿误差及未收到的停止尾段必须继续显式保留。

## 6. 其他外环 QP 结论的分类

| 结论 | 可以证明的内容及必要条件 |
|---|---|
| 刚体几何 | 经校准的 T_tcp_face 下，点法向速度 `nᵀ(v+ω×r)` 和功率共轭变换成立；任意安装不应套用简化 `vn-xω`。 |
| 有限孔径端点约束 | 点行对面内位置 c 仿射，故两个区间端点控制整个区间的新增法向速度；必须真实 c 位于该区间。若没有刚度上界，只得到速度扰动界，不能换算为固定 N 的力误差界。 |
| 力符号优先 | 在同状态、同 α 比较且 `δFdot=κ g(c)Δν, κ≥0`、原 4 N 轴标量与几何加载的单调联系成立、误差符号可靠时，`sign(F-F0)g(c)Δν≤0` 给局部附加恢复方向。不是不同轨迹的长期力误差不增定理；sign band 也需真实测量误差支持才能称可靠。 |
| 声窗分类/修复 | low-confidence 或 unknown 是声明的图像策略标签，不是机械贴合真值。速度请求和 slack 没有已证声学导数范围时，不推出声窗保持、修复收敛或贴合面积增加。 |
| α 与透明性 | α 是成功发布的参考进度比例，不是实际采集覆盖。能量等新增约束若不排除原严格凸目标的唯一最优物理解，则该解保持；不能把不同目标函数或不同观测时钟的控制器称为同一比较基线。 |
| 不可行与故障 | H/进度/视觉/相对基线行冲突属于任务不可行；只有完整六维原机械集自身为空才是机械不可行。故障不得伪造零速成功、退款、进度或 DONE。 |

硬力方向条件在未知 c 的全孔径区间下确实会限制 rocking；这不是调权重就能消除的限制。用户的原 4 N 目标与零裕量独立配对力指标目标保持，当前软件几何/能量证明不替代该实验验收。

## 必要反例与本轮验收点

1. `WᵀV=0`、r≠0：若仅 QP 扣 D 而 ledger 不扣，余额会永久不变，累计严格耗散式失效；本次 D 同账本修复关闭此漏洞。
2. 区间前半正向、后半反向：Vmean=0、真实 ∫D>0，禁止把平均速度平方当耗散上界。
3. `W(t)=L t`、V 常值：latest W 乘整段会高估输入回能；必须用同段测量和明确的积分/上界。
4. 先回能再耗能、或臂轨原本抵消但单设备先停止：终点功/零净命令不能替代前缀与停止暴露条件。
5. rail 已知 invalid 夹在两个有效点之间：不得跨段结算或释放缺口负债；最终已用统一 fence 及定向测试关闭。

证明成立的数学条件已给出，不以尚未标定为由搁置证明；同时没有将尚未满足的条件标 true 来宣称实机认证。
