# 测量源时钟与控制事务时钟：V3 裁定

日期：2026-09-10。范围仅限原 Python 力控与新 active adapter 的窄接缝；不改 IK、native、地轨协议，不复制控制器。本文是实现及验收契约，不代表尚未完成的 runtime 已通过。源码职责映射见 [MEASUREMENT_ADVANCE_MAP_V1.md](MEASUREMENT_ADVANCE_MAP_V1.md)。

**结论：新测量每个源样本只消费一次；有效保持期间，原控制动力学仍每个控制周期推进一次。** 采用独立的源身份和控制事务身份，不能用一个递增序号同时代表两者。默认 baseline/shadow 路径保持既有调用及数值行为；显式启用的新 active 路径才使用这套测量语义。

## 1. 当前真实接口能证明什么

现 `snap.t_s` 是 UDP 包在主机的接收时间，不是 F/T 传感器硬件采集时间。当前没有独立的 F/T acquisition timestamp。relay 可以重复发布同一 `snap.t_s`，同时增加 relay seq；后者不能使旧测量变新。反之，两个新源包的 wrench 数值完全相等，仍是两个真实源样本，不能按数值去重。

当前配置声明 UDP/relay 为 200 Hz。100 Hz ingress / 200 Hz control 是必须覆盖的较低更新率或丢包测试情形，不是已测得真实传感器只有 100 Hz。记录须保留声明更新率、实际源时间间隔、接收时间、各时钟域与源代际。不能把 host receive 改名为硬件 capture，也不能因一次 10 ms 间隔便宣称传感器换成 100 Hz。

图像、力、机械臂和地轨可能各有独立时间来源。用于配对的时间必须有明确时钟域和已声明的映射；真实消息中的 `realus_shared` 等标签应按生产发布链的实际含义解释，不能硬替换成 `host_monotonic` 来绕过验证。没有映射或 capture 时间时应如实记录缺项。源年龄不能仅由每次 relay 接收时刻重新起算。

## 2. 两种身份、三个时间量

| 字段 | 约定 |
|---|---|
| `control_step_id` | 每个新控制 proposal 的严格递增身份；约束单 pending、commit/abort 恰好一次。重试同一个 ID 不能再积分或再提交。 |
| `source_sample_id` | 源实例/代际与源时间或可靠源序号的组合。仅真正新源前进；同一来源的 relay 新 seq 不改变它。 |
| `measurement_fresh` | 本控制拍是否首次消费这个源样本，与“当前保持值仍有效”分开。正常重复源为 False，不等于故障。 |
| `h_exec` / `dt_control` | 本控制周期的物理执行时间，驱动命令动力、持续定时与执行记账。正常为 5 ms，不因本拍没有新源而归零或改为 10 ms。 |
| `dt_source` | 两个真正新源样本之间的接收时差；驱动源差分与按源时基实现的测量滤波。它不是硬件采样时间的无条件替代。 |
| `h_ref` | 本次候选参考区间的长度，末段可小于 `h_exec`；成功发布才提交 `alpha_accepted * h_ref`。 |

pose、全六维实测速率、wrench 的 freshness/age 各自保留；不能用 wrench 是否新鲜决定新的 pose 或速度测量是否被消费。原 `feedback_fresh` 在部分下游实际表示有效性，不能将新 `measurement_fresh` 无区别地透传过去。

相同源 ID 携带相矛盾的数值/时间不是正常保持，应显式拒绝或失效。倒时、非有限时间、旧源代际和超出年龄边界同样不能通过递增 control ID 洗成新源。合法换源须显式重置相应观察历史，并保留旧源退休及事务隔离语义。

## 3. 每一控制拍的最小顺序

1. 验证控制时间、源身份、原源时间与年龄。新源只消费一次；同源且年龄有效则使用已有测量结果，保持其原始时间和递增年龄。
2. 用当前有效的保持输入推进原控制器一次：观察分支只在所需来源 fresh 时取样，命令动力、接触持续时间、斜率限幅和机械检查仍按本拍 `h_exec` 运行。保留现有正常时基和异常周期保护；不靠累计补一个大 dt 伪造等价性。
3. 形成单个 nominal candidate，再求外环 QP。force 与 position 使用同一个候选参考区间；feedback 用已接受的 `p(s)`，区间前馈为 `Delta p / h_exec`，不提前消费参考终点。
4. 只有实际发布被确认才提交命令状态及 `s += alpha_accepted * h_ref`。未发布不提交命令积分或参考进度；已消费的新测量、真实接触转换、真实故障事实不能随 abort 回滚。
5. 下一 control step 可以继续使用同一仍有效的源样本，并重新推进一个 5 ms proposal。源测量不重消费，控制周期不丢失。到期才触发既有 stale/stop 路径；第一帧重复本身不是 stop 条件。

以上“发布被确认”不能由 prepare 成功或 solver 成功替代；逐设备失败与迟到事实仍由执行事务处理。有限测量保持也不是对旧命令无限执行的授权。

## 4. 观察与时间推进的裁定

| 职责 | 新 active 的要求 |
|---|---|
| observer 回归样本、pose ring、median 样本、源样本计数 | 每个新源最多一次；正常 held tick 不 append。 |
| 力差分、Ke 的 `Delta F / Delta x` 学习、CoP 改善证据 | 仅新配对样本更新；差分使用对应源时间跨度，不让 held tick 擦除上一真实样本。 |
| 接触获得/失触确认、recontact/hold/rearm、force ramp、stall 持续时间 | 每控制拍按物理时间推进，使用当前仍有效的保持值；状态转换事件只发一次。 |
| 导纳状态、力点/位移代理、command slew、tilt 命令角、位置参考 | 每控制拍 proposal，按实际发布结果 commit；不是 fresh-only。 |
| Ke 的命令位移代理 | 实际配置为 `displacement_source: admittance`，其积分是命令状态，不能冻结到新力样本才走一步，也不能宣称是实测位移。学习样本仍另行去重。 |
| Ke impact/settle 窗口、detach decay、质量/阻尼 slew | 保持原物理时长与每秒变化率；原 20 × 5 ms 窗口不能因改成 20 个 100 Hz 样本而翻倍。 |
| TDPA bias 与诊断功 | bias 的源观测与 `F * v_cmd * h_exec` 的时间记账拆开；保持拍仍有命令功，命令诊断不能冒充实测六维端口功。 |
| 机械/速度有效性及 stale 判断 | 每控制拍检查，保持值是否有效由年龄/质量决定；无新样本不等于新一次有效证据，也不等于立即失效。 |

接触确认可以恰在一个 held tick 达到时限。该 tick 的 acquired/lost/reset 必须恰好处理一次；不能因学习分支等待 fresh 而丢弃事件。若某个源学习初始化确需下一新样本，应在同一接触 episode 内显式保留待消费事件，不能让下一拍 `event=False` 把它擦掉。

## 5. 物理滤波时标不能靠 if fresh 自动保持

只对 200 Hz 离散滤波器加 fresh gate，在实际 100 Hz 调用它，会改变截止频率、遗忘时间和部分稳态增益。新路径必须明确声明滤波器的时间推进方式，并展示其物理时标；这是原观察算法的时基适配，不是根据合成图像效果重新调参数。

本次采用 high 已明确的最小方案：active 显式声明 `source_period_s`，在尚未消费新流样本前，一次按该周期初始化原 Butterworth/observer 滤波器；随后仅 fresh 时推进一次。**初始化状态不能一律清零：** 同周期、同有效源的模式热切换保留已有滤波状态与已消费源 watermark。首次建滤波器或显式换周期时，可由当前可靠的补偿残差设置原滤波器常值稳态（如 `lfilter_zi * u0`）；LPF 的稳定 4 N 不得变成 0 N，HP 对常值输入不应凭切换制造脉冲。无可靠样本时等待有效初始化或明确无命令预热，不能补零后允许额外压入。原接触 episode/确认定时和已消费观察不随模式初始化重放。换率暂态不宣称逐拍等价于旧滤波。

缺省不传该参数，旧入口仍保持原系数、调用顺序和数值路径。实际源间隔容许范围与保持年龄上界必须冻结并记录；导数仍使用真实 `dt_source`。有限抖动下固定周期滤波只具声明范围内的近似时标，不能称任意异步采样下精确等价。

共享 observer 的周期绑定还必须覆盖**退出 active / 切回旧模式**：不能留下按 100 Hz 设计的系数，却让旧入口重新每 5 ms 调用。退出恢复原声明周期与默认系数，重配状态仍按上面的可靠输入/状态初始化原则处理；不回滚已经消费的观察历史，不把 4 N 清零。同周期无需反复重配，模式切换不伪造一次新源。

重复包不能重新成为独立统计样本；不能每个抖动 control tick 任意重建 Butterworth 后直接套用不兼容的旧状态。发生超出支持范围的源间隔/速率变化时，应按明确的保持、重置或失效规则处理，不默默改变 Hz。单个正常 held tick 本身不触发故障；持续 100 Hz ingress 应按声明的 100 Hz 源周期验收，而不是继续运行仅 fresh 的 200 Hz 系数并声称截止频率不变。

对明确的一阶离散时间算子，设原基准周期为 `h0`，`r = dt_source / h0`：

- 标准 EMA `x_next = (1-a0)*x + a0*u`，对应系数为 `a(r) = 1-(1-a0)^r`。
- 原 Dimeas 是 `I_next = u + lambda*I`，不是标准归一化 EMA。保持常值驱动的时间递推时应为 `I_next = lambda^r*I + [(1-lambda^r)/(1-lambda)]*u`；`lambda=1` 的输入系数取极限 `r`。仅换 `lambda` 会改变稳态增益。
- 已采用 `1-exp(-2*pi*fc*dt)` 的 fast LPF 可用源时间跨度更新；三点 median 的窗口仍是三个源样本，不是三个 relay polls。

二阶 HP 与 observer 的 45 Hz LPF须单独说明设计采样率及支持的实际间隔范围。不能仅以“标量 decay 已换算”宣称整个滤波器保持了物理时标。源率降低、失采或没有硬件 timestamp 的信息损失无法由软件证明消除，记录与结论应保留这个限制。

## 6. 必需反例与验收口径

在真实原控制器上测试，不另写 toy controller 代替其混合状态。最低覆盖如下：

1. **100/200 Hz：** 1 s 内 100 个新源、200 个 control steps；观察取样 100 次、命令推进及成功发布 200 次。参考提交为 `sum(alpha*h_ref)`，命令积分为逐控制拍积分，不减半。新源仅每第二拍到达不触发故障。
2. **力斜坡：** 两个新力样本相隔 10 ms 时按 10 ms 求差分；中间 held tick 不插入零导数样本，也不更新 `_last_f/_last_x`。Ke 的 admittance 位移代理仍走两个 5 ms 时间步。
3. **滤波与历史：** 单个脉冲包在两次 relay 发布中只进入 median 一次；恒值的新包仍每包消费。按真实源间隔验证 HP/LPF 的物理时标及 Dimeas 常值驱动增益，不能只测“结果有限”。专测稳定接触 4 N 下同周期热切换与显式换周期，以及 active 100 Hz → 旧模式 200 Hz 返回：不出现 LPF 假欠力/HP 假脉冲或由此导致的额外压入，旧模式不遗留 active 采样系数；首次 held source 不二次消费。同周期有效状态应保留，换率无可靠初始化值不得虚构 0 N。
4. **持续时间及一次性事件：** 接触获得、失触、force ramp、Ke impact/settle 与 fast-retract hold 在 100/200 调度下保持原秒级门槛。专测阈值在 held tick 达成，边沿只一次且学习初始化不丢失。
5. **事务：** 新测量后的 proposal abort 不回滚测量；下一新 control ID 可在同源上继续准备，无二次观察、无虚假 command/reference commit。重复 control ID、重复 commit、过期 pending 均不能二次积分。
6. **实际时间和有效性：** 重复 relay 不刷新源年龄；合法短保持正常、超龄才走既有失效路径。另测时间 NaN/倒退、源代际切换、同 ID 异值及正常恒值新源。新 pose/velocity 在 held wrench tick 仍按各自身份处理。
7. **功与参考：** 持续相同 wrench 但有实际运动时，各控制间隔的功不丢失；bias 观察不重复。`alpha=0` 不提交参考；最终短 `h_ref` 仍用完整 `h_exec` 计算前馈及能量持有区间。

透明性必须分别报告：

- **baseline / shadow：** 旧入口、旧参数和旧测量调用语义下，输出及相关状态逐元素等价；shadow 无发布候选的权限。
- **active、QP 非约束：** 与使用同一去重观察语义、同一控制时钟的共享 nominal 逐拍等价。不能把它表述成“100 Hz 源下仍等价于旧路径重复滤波 200 次”。正确修复源处理语义可以改变观察量；原命令动力、参数及其 200 Hz 时间推进不能因此被悄悄更换。

这些是软件接口和状态语义验收，不是声窗改善或真实力指标非劣性的证明。真实采集入口无需等待合成声学效果 PASS；主动控制仍须满足已冻结的真实几何、单位、机械保护、时间和事务接口要求，未知实测外参不得由仿真值补齐。

## 7. 同一测量中的原 4 N 定义不可更换

`QpInput.force_n`、原力误差、力优先触发和力指标验收继续使用原 controller 的 `normal_sign * f_ext_z`，包括同一套已声明补偿和原控制轴。不能把它替换成 face 法向投影 `-n_into dot W_force` 后仍称保留原 4 N 目标。

实际 face 法向及刚体变换用于局部压入速度几何；能量使用对应物理端口的完整六维 wrench 与 twist。这两个用途不改变原力指标轴。原轴与 face 法向有夹角时，sign-only 局部压入限制与原轴力变化之间需要安装及接触单调性条件；刚体速度关系本身不证明力或声窗单调性。允许的安装条件应明确验证，不能用暗换目标投影弥补未知几何，也不能无依据要求完全共轴。真实六维端口的正负号转换与该原控制标量应分别记录，避免把控制器内部符号直接冒充物理功符号。
