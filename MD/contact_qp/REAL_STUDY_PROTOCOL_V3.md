# v3：真实特性记录与效果判定

本文件落实用户的最新要求：软件与几何关系验证完成后，交付由用户主动运行的真实控制入口；不等待合成声学效果通过，不把离线回放当作新控制器的闭环实验。本任务没有启动机器人、重启已有控制服务或订阅实时设备。

## 控制器究竟怎样更新

第 k 幅真实超声图像经过固定版本的 confidence 提取器，产生左右质量观测。QP 使用当前有效观测、最新力与实际姿态求本拍速度。下一幅图像的质量仍然由真实图像重新测量，不由仿真器预测，也不从上一拍命令推算。

已知安装几何时，窗口点速度是 `v + omega × r` 的法向投影；这条关系可解析验证。但局部压入导致 confidence 上升是待检验的策略假设。阴影、入射角、组织结构、失配时延都可能使假设不成立。可选动作—响应一致性只能根据配准后的实际累计运动调整修复请求；默认关闭，不替代测量，也不关闭已改善声窗的保持项。

因此有两个独立问题：控制器是否按设计求解、发布和提交状态；这个设计是否改善当前探头和组织的声窗。前一个问题在软件与声明机械模型中验收，后一个问题需要新采集的真实数据。

## 真实记录如何区分问题来源

| 从同一次运行提取的证据 | 可以判断的问题 | 不能由它单独推出的结论 |
|---|---|---|
| 名义速度、QP 速度、约束活动情况与松弛 | 外环是否提出了修复，是否被力方向或孔径策略限制 | 正松弛不证明组织无法修复 |
| 最终臂轨发送事实、预测速度、完整实测运动及时间 | 动作是否发送、是否实际发生，延迟和 IK 跟踪偏差有多大 | 发送成功不证明实际运动等于 `v_cmd` |
| 原始图像、配准版本、左右质量与实际窗口位移 | 动作后声窗是否响应、方向先验是否适合该区段 | 一段自然扫描的相关性不证明动作因果 |
| 当前 4 N 控制误差及独立运行级统计 | 新算法的力精度是否满足零退化要求 | 几何符号约束不证明全轨迹力精度不变 |
| 独立实测路径上的有效与缺口区段 | 改善是否覆盖了更多路径，是否只是扫描更慢 | 参考进度或完成状态不能代替实际覆盖 |

这个记录结构支持逐层定位：没有修复请求、请求被约束限制、命令未执行、图像对时失效、实际动作发生却没有声学响应，应分别保留。不能都归为“QP 效果不好”，也不能统一靠调大图像权重处理。

## 用户启动的入口与配置

原控制器可直接配合被动 H5 记录获取新特性；不要求先补完外环几何。准确命令、已有流程是否包含机器人运动以及解释器见 [REAL_CAPTURE_ENTRYPOINTS.md](REAL_CAPTURE_ENTRYPOINTS.md)。原始记录保留建立接触、扫描、停止与失败尾段；新 sidecar 补充候选、逐设备发布和预算事实。图像工作进程独立于 200 Hz 控制线程。

新增 study 配置有 baseline、shadow 和 active 三种选择。baseline 使用原控制并记录；shadow 额外记录候选；active 才把外环速度交给原 IK。shadow 是可选诊断，不是必须完成的审批阶段。各入口实际完成情况以 [STATUS.md](STATUS.md) 和对应审核为准。

主动 QP 使用实际孔径、`T_tcp_face`、图像左右映射、时间配置和固定的质量判定版本。模板中的空值就是未知值，不能用 synthetic 默认值填补。质量阈值应作为真实图像上的任务判定规则冻结；confidence 本身不是接触概率。未知的物理能量误差/停止界保留监测或命令模型标签，不伪装为无源认证。

`--validate-only` 只检查磁盘代码和配置。已经运行的旧 Python 服务可能不认识新模式；主动提交前还必须确认正在运行的服务具有相应能力，不能把 ACK 或客户端自填 label 当作新外环已经安装的证据。这个检查属于防止静默运行错误版本的软件接口，不是新增用户批准步骤。

## 新数据怎样支持改进

先用一组明确标识的真实设计记录检查图像时差、质量判定与局部运动响应。保留无响应、反向响应和不可解释区段；不从中学习完整 image Jacobian。修改只能针对已观察到的问题，例如错误轴向、重复时差、旧帧、未执行的命令历史，或者在既定力精度要求下不合理的策略请求。

若相对完整接触区间的力方向条件使所需 rocking 不可行，应报告耦合可行域，而不是以更大权重掩盖它。是否改变这一策略及其依赖假设，需要新版本的论证；不能把压力中心直接当作增量刚度中心。对真实声学无响应的区段，保留缺口并继续扫描的既定行为仍适用。

选定算法、几何、窗口、质量阈值和参数后再冻结版本，使用独立真实运行做配对验收。原控制器、联合 QP、匹配扫描速度与匹配 rocking 的对照用于区分收益来源。力 RMSE、绝对平均偏差和峰值误差的单侧 95% 上界要求仍为零退化；统计单位是独立实验运行，不是同一运行中相关的控制帧。实际覆盖、缺口长度、恢复时间、完成时间和中止率同时报告。

若独立验收失败，保留失败版本，后续修改进入新的设计与验收版本。旧真人数据可用于分析与接口回放；合成机械实验可用于约束、时序和故障反例；二者均不替代新算法的真实闭环效果证据。
