# v8 力与声窗分配：编码前数学裁定

状态：**方案裁定，尚非实现 PASS**。本轮用户已授权将策略改为原标量 4 N 偏好、修复软边界 4.5 N、硬监督阈值 6 N。原先零退化的两端 `sign(F−4)·δr≤0` 不再是 v8 规则；旧策略须版本化保留。内环 IK/native 不改。以下只定义可检验的软件策略与条件性质，不宣称真实声窗修复或峰值力已获认证。

## 1. 差分任务必须由 rocking 承担

三物理变量仍为 `y=(vn,ω,α)`，完整原 TCP twist 为 `V=Hy=E[vn,ω]+αb`。令 `Pi` 为现有完整几何计算的左右窗法向速度行，`D=PL−PR`；从每帧有效观测计算 `ei=max(cmin−ci,0)/cmin`、`loss=max(eL,eR)`。

**采用总 rocking 的单侧最低请求，不采用每拍必加的增量请求。** 这样已有足够且方向正确的原 tilt 可以保留，原 tilt 方向错误时任务要求向正确方向转变；共同压入不再冒充左右差异修复。

令 `s=sign(eL−eR)`、`qD=v_diff·gF·|eL−eR|`，增加无量纲辅助松弛 `ξD≥0`：

```
s·d + vscale·ξD ≥ qD
J_diff = wD·ξD²,  wD>0
```

当前真机声明几何下 `d=DV=−.031ω`，公共 vn 和 α 精确消去。一般安装若 `Db≠0`，取 **rocking 分量** `d=DV−αDb=DE[vn,ω]`，以免减速替代该任务；需明确这是一项动作分配策略，不伪称完整局部速度的导数保证。先校验公共平移系数为零且 rocking 系数非退化，不对退化安装强行除零。

仅在 `qD>0` 时激活该单侧任务。没有左右差异时，不人为指定方向；两边共同缺失仍通过原共同修复任务处理。左右缺失符号翻转应镜像翻转请求方向。

将现有原名义动作距离、公共修复/保持软项保留。新增一个凸平方将未服务的差分请求与扫描损失关联：

```
alpha_pref = 1 − kq·loss
J_progress = walpha·[alpha − alpha_pref + kxi·ξD]²
```

`J_diff` 独立保留，因此降低 α 不能消除差分欠服务代价；禁止将差分请求乘 α，也不引入 `α·ξD` 双线性项。该耦合是软目标，不能硬设质量驱动 α 上界而破坏已有减速度可行性。硬机械/能量不可满足时不承诺“必有 tilt”；软件验收须检查有充足余量的非对称例产生可观的正确方向动作，不能以数值噪声充作服务。

## 2. 4.5 N 软边界与 6 N 监督的真实含义

无接触刚度、执行误差、延迟和停止暴露界时，**不能构造可信的下一拍牛顿上限**。可立即实现的 v8 是测量反馈策略，例如：

```
gF = clip((4.5 − F_upper)/.5, 0, 1)
```

其中 `F_upper` 只有在存在真实测量误差界时才是上界；否则必须标记为当前测量估计。4 N 仍通过原名义力控制及名义动作偏好体现。声学任务随 `gF` 降权，可对新增正端点 loading 另加软惩罚：`zj≥Pj(V−Vnom), zj≥0`，惩罚权重随测得力超过 4 N 增加。这些辅助量不是新物理状态、力预测或能量罐。

**必要边界：** `gF=0` 时关闭声学修复/保持/差分动作任务；不能仅把正请求改为零而继续高权重施加 `r+ξ≥0`，因为它会惩罚高力时原名义的回撤。此时保留原 4 N 名义回路及未被门控抹掉的图像 loss→α。4.6 N 的典型结果应是允许原控制回撤并减速，而非继续为坏图加压或恢复快速扫描。

对新鲜的原控制轴标量达到 6 N，退出普通视觉 QP，沿原监督停止链处理；陈旧/缺失力样本不能继续被视为可信低力。**阈值监督不等于连续时间峰值≤6 N 的物理保证。** 用户使用的“硬6 N”须同时说明这是当前监督硬阈值，还是具有完整下述界的预测安全约束。

若提供了真实、版本化且在任务区间有效的界，可增加保守预测辅助变量：

```
u ≥ Pendpoint,j·V + |Pendpoint,j|·eta_v,  u ≥ 0
Fub = Fmeasured + epsilon_F + DeltaF_old
      + kappa_total_upper·h·u + DeltaF_disturbance + DeltaF_stop
Fub ≤ 4.5 + sigma_F,  sigma_F ≥ 0       # 软约束及平方代价
Fub ≤ 6                               # 硬约束
```

这里总接触刚度上界不是随意指定的点刚度；其成立依赖原控制力轴的加载单调性、全孔径局部速度上界、旧命令/延迟/运动表面扰动及完整停止暴露均已包含。停止项若取常量，须覆盖该配置允许的全部动作；不能只覆盖静止或理想 IK。缺任一必要界，预测模式必须明确关闭，不能塞入“保守猜值”后将旗标置真。

## 3. 与原单 tank 的兼容性

力/修复辅助量不改变物理 `V=Hy`，也不另建 tank。保留现有 `PortEnergyConstraint` 对 **完整六维 TCP 速度** 的单共享行：

```
WmᵀV − epsilonᵀ|V| − rhoᵀ|PcV| − C_tracking ≥ −beta·S_available/h
|PcV| + |Pc|·eta_v ≤ rbar             # rho 所需的实际速度界
```

绝对值仍用原线性辅助量。不得只对新增修复速度检查能量，忽略名义 pressing、路径或其他旋转；最终 payload 模型仍按实际复核时刻重算六维行。发布事务、未结算负债、缺测不退款、同账本扣净端口功与 D 的规则保持。能量硬行与真实机械硬行优先，视觉/4.5 软任务不能穿透它们。

`S=0` 不意味着全部速度必须为零：允许回能或确实零净耗能的动作。测试 rocking 的能量限制时，所设 wrench torque、D 或不确定性必须让该 rocking 确实消耗能量，不能用零转矩零耗散的模型却要求它停止。

当前实机配置 `energy_constraint_enabled=false`、`physical_w_checked=false`，且已观测有效端口覆盖约 21%；这些记录**没有证明 tank 为扫描提供了能量约束**。v8 可交付已验证的可选命令预算接线和完整测量诊断；真实 W 符号/参考点/单位核对、时间对齐与误差/停止界是启用对应保证的条件。未满足时保留 disabled/unavailable/estimated 标签，不能为了宣称“用了能量罐”扩大初始余额、补造实际速度或跨缺口回能。

## 4. 最少必要反例与验收

1. 日志 5641：`qL=.41558,F=3.6402`，原公共 vn=4.453 mm/s 不能满足差分；原 d≈.45546 mm/s，小于未衰减请求 .96106 mm/s，对应目标总 ω 约 −1.776°/s。slew 或能量受限时可逐步提供，但必须记录差分请求、服务量、松弛和限制原因。
2. 1452 及 F=4.2 N：旧零退化端点行不再冻结修复；在允许的软压力权衡下产生正确方向 rocking，且完整孔径/机械/能量行仍满足。原名义已充分正确的 rocking 不被要求无用追加。
3. F=4.6 N：声学动作任务不能阻止名义回撤；F≥6 N、缺测、停止或部分发布不提交新动作/进度。无模型界时日志不声称预测峰值认证。
4. 能量充足与能量为零分别测试同一输入；只要选定请求确实耗能，能量行能抑制它，保留可行回能。差分/力辅助量不可产生虚构 credit。
5. 正常图像、左右对调、两侧共同缺失、未知图像及机械 slew 冲突；验证 q 正常时透明，符号镜像正确，降低 α 无法在代数上满足差分行，硬约束不能被软松弛绕过。

本轮末尾黑带的 q 仍可能高于 .8。分配器只能处理收到的缺失信息，**不能靠改分配修复未被特征检测到的缺失**；不把该限制隐藏在新的 tilt 公式后面。
