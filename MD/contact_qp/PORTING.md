# 外环边界与移植说明

现行设计依据 [ARCHITECTURE_REVIEW_V2.md](ARCHITECTURE_REVIEW_V2.md)。实现与验收进度见 [STATUS.md](STATUS.md)。仿真不是患者声学模型；其图像生成器不能用于预测真人响应或替代真实闭环验收。

## 控制链

```text
最新有效 wrench、实测位姿 → 原 4 N 力控与零力矩导纳候选
当前已接受路径参考       → 路径速度与位置反馈
最新真实图像特征快照     → 左右声窗任务
上述输入 + 单一能量快照  → 外环 QP [vn, omega, alpha] → v_cmd
v_cmd                   → 原 IK / 原机械保护 → 分设备发布事实
实测运动与后续真实图像   → 运动历史、质量记录、可选一致性更新
```

QP 不预测下一张超声图像。局部接触速度来自标定后的刚体几何；下一拍声窗质量重新从真实图像提取。一致性机制只调整修复请求，默认作为关闭的消融选项，不学习完整图像 Jacobian，也不提供声学收敛证明。

## 模块边界

| 文件 | 责任 | 移植时的输入要求 |
|---|---|---|
| `peirastic/contact_qp/types.py` | 版本化、只读数据接口 | SI 单位、有效时间、坐标系和标定版本必须明确 |
| `geometry.py` | TCP/接触面刚体变换、窗口局部速度、功率共轭 | 声学孔径长度、`T_tcp_face`、图像左右物理映射 |
| `qp.py`、`port_constraint.py` | 同一个外环联合求解与最终速度复核 | 原名义动作、路径、机械许可、完整物理 wrench 和单预算快照 |
| `features.py` | random-walk confidence 和版本化窗口观测 | 原始图像、crop/hflip、采集时钟和已确认的延迟配置 |
| `history.py`、`coverage.py` | 实测动作历史、可选响应策略、实际覆盖 | 完整实际运动与图像有效时间；命令不能冒充实测 |
| `force/nominal_transaction.py` | 名义候选、提交与拒发分离 | 测量状态只推进一次；发布事实决定命令状态提交 |
| `apps/contact_qp_features.py` | 独立图像工作进程 | 现有图像流的消息身份与时间元数据；不连接机器人 |
| `force/contact_observer.py` | 控制线程读取最新特征快照 | 非阻塞输入；图像失效必须显式传播 |
| `plant.py`、`apps/contact_qp_experiment.py` | 声明模型范围内的仿真与故障反例 | 仅用于开发与机制检验，不移入真实控制链 |

除 `types.py` 外，表中简写路径相对于 `peirastic/contact_qp/`；`force/` 相对于 `peirastic/realman8dof/`，`apps/` 相对于 `peirastic/`。核心计算依赖 NumPy、SciPy、ProxSuite，不依赖机器人连接、GUI 或共享内存。

## 真机配置与证据

仿真几何和 `c_min=0.5` 都不是已经完成的真人标定。真实孔径、接触面相对 TCP 外参、图像左右映射以及特征窗口/阈值必须单独保存版本；缺项时输出待标定状态，不能给仿真参数改一个 `verified` 标签后使用。

原控制器可以用于记录真实特性，新 QP 可以旁路记录候选。主动 QP 的软件与机械接口验收和声学效果验收是两件事：不要求合成声学效果先通过才开展用户主动启动的真实实验；真实收益必须由新采集的配对闭环实验判断。本轮不自动连接或启动机器。

当前 TCP 保持原物理转动基线。环境对探头的物理 wrench 与压缩为正的力控输入分别记录。完整端口功是同点同系的六维内积，不能逐轴截正后相加，也不能额外扣一次 `4 N * vn`。外环命令能量条件不要求在原 IK 中增加能量代价。

4 N 误差始终使用原力控轴和原 `normal_sign * f_ext_z` 标量。倾斜安装接触面的法向力投影可以另行记录，但不能悄悄替换目标力的定义；接触面几何用于窗口局部运动，六维物理 wrench 用于端口功。

原 IK 最终输出与外环期望可能有残差。最终载荷对应的组合 TCP 命令模型速度用于重查能量行；该检查不要求把声窗策略塞入内环。它通过时只说明命令模型的能量条件可接受，不证明全部外环任务条件仍满足，更不证明实际速度已经跟踪。相对策略偏差与实测残差分列记录，不能以很小的 H 子空间数值容差把正常 IK 输出全部拒发。

真实端口误差、保持时间和停止范围未经测量验证时，能量只能标为监测/命令模型约束。`v_cmd`、最终发送速度、执行预测和完整实测速度须分列；发送成功不证明已实现相同物理运动。

旧 native 通用约束分支保存在 `experimental_native_v9/`，已经退出主链，不属于移植依赖。旧 `execution.py` 及其专用 helper/tests 已移到该目录的 `coordinator_snapshot_20260910/`；生产链保留单一 `energy.py` 账本和 `runtime_energy.py` 适配器。

真实 tracker 尚不提供 `port_time_aligned` 和端口标定版本，当前实测能量结算因此为 `monitor_unavailable`。默认不启用命令预算；显式启用时只有命令模型准入，未结算预留不会自动回补，可能耗尽后停止。不要把源码接口存在理解为真实能量反馈闭环已接通。
