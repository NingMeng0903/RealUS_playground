# v3：最小真机外环与真实特性采集的独立审查

2026-09-10，依据用户最新纠正重新确定范围。本文替代“继续依据 synthetic 声学效果调参”的建议；不修改生产代码、不连接设备、不自动启动运动。已完成的 A/B 软件修复及旧失败结果保留，纯外环能量模块另行审查。

**合成图像不是患者/探头声学世界模型。不能以其效果 PASS 作为用户主动运行真机的先决条件，也不能用其最佳阈值、响应增益或缺口持续时间标定真实控制律。** 本轮应交付最小外环、清楚的运行边界和可追溯的真实数据，之后由真实动作响应判断方法是否有效。

## 1. 三类结论必须分开

| 结论 | 成立依据 | 本轮能否直接给出 |
|---|---|---|
| 刚体几何关系、力矩/速度坐标变换 | 实际标定的参考点、安装变换、法向和图像轴；同点功率共轭 | 软件公式可验证；真实外参仍须实际给定 |
| 命令层或条件物理端口能量不等式 | 同一外环的完整六维能量行，以及明确的 wrench/时间/执行误差与停止条件 | 可在声明条件下验证；缺实际界时只能 MONITOR/UNVERIFIED |
| 声窗改善、维持或收敛 | 真实采集的质量、实际动作、时序以及必要的声学响应假设 | 当前不能由刚体公式、能量约束或合成 renderer 推出 |

真实 confidence 每幅图直接计算。下一幅真实质量是下一次测量，不由 renderer、假组织模型或当前动作外推出来。sign-only 的局部压入方向是一项名义策略；正确的几何方向不等于 confidence 必然上升。可选 gamma 依据对时的实际动作响应，默认消融关闭，不能被称为 Jacobian 学习或声学导数证书。

[DIAGNOSIS_V2.md](DIAGNOSIS_V2.md) 已证明的终点 H/加速度冲突、重复使用旧图与错误状态分类有软件意义；其“160–195 ms 后缺口已恢复”“二值深度 renderer”“纹理独立大波动”等发现首先限制的是该实验的解释能力。不能把这些合成比例当作真实机器的时延、有效性或最优参数。

同状态名义反事实也没有支持“极小 QP 数值差导致当前配置发生巨大力偏差”：1638 拍中 ±10⁻¹³ m/s 对下一名义输出的最大影响约 4.52×10⁻¹³ m/s，随扰动量级近似线性；实际配置的弹簧刚度和 proactive FF 均关闭。见 [名义反事实记录](nominal_same_measurement_diagnostics.json)。因此不以这个未获支持的猜测修改原力控。

## 2. 最小交付只需要两个用户主动入口

**原控制旁路记录（可选附带 shadow 求解）：** 用户继续使用原 4 N 力控、零力矩导纳、原 IK 和已有操作流程。新增记录器采集真实图像、力、动作及时间；可在旁路计算外环候选，但候选不进入发送和命令状态提交。此入口不需要先证明新控制有效，也不应因探头孔径/安装外参尚未标定而阻止记录原始数据；未知项明确留空/UNVERIFIED。

**主动外环 QP：** 用户显式选择后，原名义控制 → 三物理变量外环（含共享能量条件）→ `v_cmd` → 原封装 IK/机械保护。图像不进入内环 QP，不增加侧向搜索、目标力自适应或额外控制器。软件必须保留实际发布、实际运动和参考推进的区别。

shadow 是可选的诊断入口，不是新的强制分级审批。主动入口不等待合成声学效果通过；它需要的是真实几何/单位/时间接口可用、原机械保护完整，以及相关软件验收完成。本文描述交付边界，不把尚未实现或标定的主动入口说成已经可用；用户现在即可沿原控制链采集真实特性。

主动入口的最小进入条件是：

- 孔径与 `T_tcp_face`、图像左右映射、控制轴、单位和 wrench 符号明确；版本不一致、非有限值或未知几何不能偷偷使用 synthetic 默认值。
- 力和全末端运动反馈有时间、有效性及来源；当前力用于力控/能量，图像只按其有效采集时刻使用。已知延迟不能当作零延迟，测量失效不能由命令值伪造实测值。
- 原关节、碰撞、速度/加速度、看门狗和停止接口保持；发送拒绝/部分未知不推进参考，不回滚已经发生的物理运动；命令候选未发布不提交积分器。
- QP 的 SI/坐标、机械边界、能量行、求解失败、正常/数值终点收尾及名义透明性测试通过；原运行链回归通过。主动算法效果仍是待测结果。
- 能量模式明确。已验证整拍误差/暴露界时才使用物理认证措辞；未知时可运行明确标注的监测模式和已有机械保护，但不能声称严格患者端口无源/耗散。未知认证条件不是强迫用户先完成一轮 shadow 的理由。

## 3. 最少必要的真实数据

记录目的，是把“哪幅图、哪段实际动作、哪次命令、哪项能量假设”对应起来。数据字段可按传感器原频率分流保存，不必把图像解码或磁盘写入塞进 200 Hz 控制回调。

| 数据流 | 最少字段 |
|---|---|
| 一次运行的固定信息 | 源码/配置版本；4 N 目标；旁路/shadow/active 模式；窗口/crop/flip/质量算法版本；实际几何及其验证状态；坐标、单位、时钟与能量模式 |
| 每幅图像 | source/instance 与 frame ID；原始图像或可追溯的无损帧引用；设备采集时间（若有）、接收时间、有效采集时间及所用时延；LEFT/CENTER/RIGHT 质量与有效标志 |
| 力与姿态反馈 | 原始/处理后 wrench、时间和有效标志；控制正压缩力与物理六维 wrench 的明确区分；当前 TCP 位姿；传感器零偏/载荷补偿和变换版本 |
| 实际运动 | 完整实测 TCP twist、其积分区间和有效性；可追溯的机械臂实测关节状态与轨编码器样本/时间。预测速度、命令差分不得标为实测 |
| 命令事务 | 名义 twist、QP 候选、最终发送量；候选/发送 ID、逐设备结果与时间；接受 α、`h_ref/h_exec`、参考时钟；实测路径位置；QP 状态、活动约束及视觉松弛 |
| 能量开启时 | 同一 tank 的余额/已占用额度、能量行余量、完整物理功积分区间、结算状态；使用的误差/耗散/停止界及其来源；界失效和执行偏差，不隐藏负余额 |

若启用 gamma，再记录其有效图像对、对应实际局部位移、拒绝证据的原因及更新值即可。没有必要为此增加声学状态预测器。CENTER 保留诊断，LEFT/RIGHT 始终是原任务要求。

以下量必须来自真实接口或实际标定，不能由合成模型代填：

1. 实际有效孔径半长、TCP 到声学接触面的刚体变换、面法向、rocking 正方向、图像横向/裁剪/翻转映射。壳体宽度、模型碰撞网格或图像视野宽度不能自动替代它们。
2. 力传感器到 TCP 的变换、零偏与载荷补偿、物理端口符号/参考点；处理延迟和有效采样时间。变换验证应检查同点 `WᵀV` 保持，而不仅检查法向力数值。
3. 机械臂与轨真实反馈的时钟关系、速度计算区间、反馈时延、更新缺口和执行误差。一次观测到的 `|V_actual−v_cmd|` 不是未来整拍误差上界。
4. 如需物理端口认证，另需 wrench 测量误差/整拍变化界、可覆盖旧命令与停止过程的实际运动误差或暴露界、停止能力及时间界。只能从足够的真实验证和明确运行范围给出；有限样本最大值不能自动宣称全局确定界。缺这些量仍可记录实际功，但不能提升保证等级。

不要求识别患者刚度、学习图像 Jacobian 或恢复接触压力分布。

## 4. 真实特性采集怎样验收

先验收数据能否回答问题，而不是先要求控制优于基线。用户沿原流程运行时，确认图像/传感器身份连续可追溯、时间关系可核对、实际动作和命令不同、图像失效不会变成好图、停止尾段仍被记录。已有自然法向/rocking 变化可以用于观察响应；无需为了“激励充分”新增动作权限或提高力目标。

用户主动启用 QP 后，在相同机械许可内记录候选与最终动作。判断某次响应时，对照**两幅真实图像的有效采集时刻之间**实际局部动作，并报告同期力、扫描位移和组织/视野变化。收到旧图之后发生的动作不能解释那幅图；同一帧被复用多拍也不是多个独立响应样本。没有足够动作或受到混杂时，结论是“本次响应不可判断”，不是“组织不可修复”。

由用户/实际采集目标定义真实声窗有效性及阈值含义；confidence 本身不自动等于机械接触真值。先分清接触缺口、声影、视野变化和评价任务，再决定是否改变阈值或启用响应策略。机械/命令测试可全部通过而声学任务仍无收益，这种结果必须允许出现并如实交付。

刚体和能量验收的成功不能代替力精度与覆盖效果比较。**用户要求的零裕量力指标与冻结参数后的独立配对效果验收继续成立，也适用于后续真实效果比较。** `acceptance_v1.json` 中具体的 scenario/seeds 只定义其合成实现；真实实验的配对单元、数据划分和任务须在相应评估采样前冻结，不能用逐帧样本或合成种子替代独立真实实验单元。此效果验收不是启用真实记录的前置批准，也不等同于临床有效性认证。不能从收到的图像事后挑最佳片段或削弱原力指标。

## 5. 当前力方向条件的明确建议

**最小交付保留现有 hard force-priority 策略，不在本轮接机工作中放宽、缩小 0.1 N band 或借合成结果改权重。** 同时从说明中删除“它保证整段力精度不劣”的暗示；它不是附件能量定理的必要组成，也不是任意图像可修复的保证。是否保留为最终性能方案，之后用实际特性和单因素比较决定。

其不可兼得边界现在就能说明：在完整未知中心区间 `[-a,a]`、可靠超力符号下，两端约束给出 `Δvn≤−a|Δω|`，孔径内部没有相对同拍基线的新增压入；欠力时则反向要求公共新增加载。这种耦合不能通过增大视觉权重解决。

而在 ±0.1 N 符号不可靠带内，现策略允许预算范围内的新增压入；因此不能据此保证精确维持 4 N。合成 shadow 中的偏差暴露了这一逻辑边界，但不提供一个真实机器应使用的新 band。缩小 band 需要真实测量误差依据；同时强制两个力符号会让全孔径附加修正退化为零，几乎关闭修复，不能包装为同时满足所有目标的技巧。

同样，现有 MotionHistory 可以提供“旧图之后已经执行多少局部动作”的可追溯证据，但把它换算为该图的修复请求已经完成，仍是一项**动作额度策略**，不是已知声窗恢复量。现在记录该量，不默认为真实改进，不据此降低未知图像 max loss、删除必需窗口或宣称当前质量已好。可选 gamma 也不能改变缺口统计；既有坏图导致 alpha 慢扫的问题应作为待测政策限制明示。

## 6. v3 冻结与交付范围

本轮只推进三件事：保留已证软件修复；完成最小外环与原控制旁路记录/用户主动 QP 入口；采集可核对的真实特性。**不新增基于 synthetic 图像的效果调参循环。** 已通过的 A/B 是软件实现结论，B 仍默认关闭，不预设其在真机上改善性能。

代码/接口回归仍可使用解析反例和合成机械 plant。需要跑新设计集时，使用独立 v3 目录与源码/config manifest，保留 v2 原结果；它验证接口、时序、账本和数值行为，不充当声学世界模型。所有真实采集同时冻结几何/时间/特征版本；版本改变开新记录段，不能把变换后的前后数据混成同一个响应实验。

固定 F0=4 N、LEFT+RIGHT、原机械保护、零统计裕量与 held-out 隔离不变。尚缺外参保持待标定，实机物理保证保持 UNVERIFIED；不得偷偷用仿真参数补齐。是否启动、如何运行仍由用户主动决定，本审查不调用硬件、不引入额外审批流程。
