## 裁定：恢复外环边界，承认实现顺序偏移

用户所说“外环输出 v_cmd，原 IK 理论上不用动”符合首版算法边界。主链应为：

原 4 N 力控与零力矩导纳 → **同一个外环 QP 联合求解 `[vn, ω, α]`，包括一个共享能量条件** → `v_cmd = H y` → 原 IK 与机械保护 → 发布事实和完整实测反馈。

附件式（23）、（30）已经明确这一点。当前 `QpInput` 只有标量 `force_n`，没有完整 wrench、tank 或能量行；Stage 3 先实现了发布端宽速度包络预留和 native 约束，尚不能让有限能量参与外环三个变量的联合选择。这是工作顺序和架构重点的偏移，应先纠正。审查之前接受的 native 通用行与严格双映射认证，是更强的实施方案，不能当作外环方法不可避免的要求。

**840 次 design_v2 仿真只有笛卡尔 plant，没有 native IK，也没有能量账本。** 它们可以暴露视觉/力/进度策略问题，不能作为完整能量外环的效果验收；其中效果不佳也不能归因于 native 的新增项。

按本轮已决定的恢复范围执行：归档 Stage 3 差异后，将 native 协议、客户端、C++、构建标识及 runner/rail 中新增的通用证书发送分支恢复到原封装。逐文件、逐修改块恢复，保存用户原有修改，不能用整树覆盖代替审查。保留 Stage 1 的完整实测 twist 通道、时间/有效性转发、名义控制器 prepare/commit/abort 和已证明的状态修复。纯 `energy.py`、`execution.py` 可作为未接入运行链的研究库保留，不作为新硬件启动条件。

## 能量保证分三个等级，不需要把它写进关节 QP 代价

| 等级 | 实际含义 | 原 IK 是否必须改动 |
|---|---|---|
| 理想执行下的外环能量约束 | 假设整个积分区间 `V_actual = H y`，在外环限制完整六维净功 | 不需要 |
| 实测监测 MONITOR | 用有效、对时的完整实测运动和 wrench 记录实际功、执行误差；异常时调用已有停止接口 | 不需要；事后测量本身不构成事前硬保证 |
| 声明误差界下的物理端口保证 | 所有实际运动含旧命令、时延和停止阶段均被已验证的整拍误差/暴露界覆盖 | 可以在外环用保守误差项实现；native 硬行只是可选增强，也不能单独证明真实执行 |

患者作用于探头的 wrench 为 `W`，与速度须同参考点、同坐标系。`e = V_actual − v_cmd` 时，实际输入功率为 `Wᵀv_cmd + Wᵀe`。控制器的“正压缩力 4 N”不等于环境端口 wrench 的正 z 分量。功率必须六维先求和；不能分轴正部相加，不能再重复扣 `F0*vn`。

“臂轨抵消但地轨先停”的例子只是在说明 `v_cmd=0` 不保证实际速度立刻为零：原来臂与轨分别贡献 `+u`、`−u`，轨停止而臂持续时实际速度是 `+u`。这是真实执行偏差和停止暴露，不是能量应成为内环 QP 项的理由。若已有整拍末端误差界覆盖它，外环可以统一扣其最坏功；没有界时记录 MONITOR/UNVERIFIED，不能靠修改 native 行声称已经认证。

附件式（5）的精确跟踪是假设，用于将命令层定理提升为真实端口定理；它不要求把任何微小 IK 松弛都升级为普通扫描的硬故障。主链保留命令、实际运动及偏差的区别。参考时钟只在发布成功后推进；物理覆盖另由实际位置与对时图像重建。停止/收尾冻结参考进度，仍记录真实位移、功和图像，不能强迫安全制动留在当拍扫描 `H` 子空间。

## 给 HIGH 的两项实现及数学验收条件

### 1. 共享平滑参考与明确收尾

先修改各对照共用的参考，使位置与其前馈速度一致，并使正常起止符合已声明加速度许可。终点后的有限减速度收尾有明确阶段，`α=0`，使用已有机械停止接口；普通任务不可行、求解器数值失败和物理机械边界不可行分别记录。达到参考时间不等于完成实际路径，不能放宽距离门槛或剪掉停止尾段来消除失败。

若前馈改为参考区间平均值，位置反馈仍使用当前已接受参考 `p(s)`，不能顺手换成未接受候选终点 `p(s+h)`；后者额外加入前视反馈，在 `α<1` 时尤其改变原跟踪语义。明确区分末尾参考增量 `h_ref=min(dt,T−s)` 和真实保持时长 `h_exec=dt`：前馈位移除以 `h_exec`，参考只增加 `α*h_ref`，机械/能量/实际时间仍使用 `h_exec`。若真缩短执行步长，则所有 plant、发送、测量和能量接口必须一致采用该短步长。零速参考的启动可用首区间平均前馈，不允许给零路径伪造接受进度。

必须保留并复现这个独立反例：原路径速度为 `+0.01 m/s`，`h=0.005 s`、该轴加速度上限 `1 m/s²`，下一拍允许速度为 `[+0.005,+0.015] m/s`；新 `b` 仅为 `−0.0001 m/s` 时，`α∈[0,1]` 只能给出 `[−0.0001,0]`。完整机械集合中存在制动速度 `+0.005`，而普通路径子空间内没有解。这个失败不能叫“机器人机械不可行”。平滑参考与独立收尾后，应在原终点失败种子上验证修复，再扩大设计集回归；所有对照接受相同改动。

### 2. 在外环加入附件式（30），先保持 IK 不变

令 `V=Hy`、`r=P_c V`，`S_free` 为单一余额扣除已占用预算和停止保留额后的可用量。引入代数上图量 `t≥±V`、`z≥±r`，加入一条共享行：

```
W_mᵀ H y − (ε_W + h L_W/2)ᵀ t − (d ⊙ rbar)ᵀ z ≥ −β S_free/h
0 < β ≤ 1
```

`ε_W,L_W,d` 非负、有限，量纲分别对应 wrench 误差、变化率和声明耗散；`rbar` 界定实际接触速度。`H` 包含全部允许路径、位置反馈和计划姿态，因此能量可以联合改变 `vn`、`ω`、`α`。不在外环解后统一缩放，不把整条候选拒发器当作联合求解。辅助变量可以多于五个，物理决策仍只有三个。

若声明整个区间内逐分量 `|V_actual−V|≤η`，在上述行左侧再扣常数：

```
q_tracking = (|W_m| + ε_W + h L_W/2)ᵀ η
q_damping  = (d ⊙ rbar)ᵀ (|P_c| η)
```

这是对 `W_actualᵀe` 及 `|P_c(V+e)|` 的保守下界/上界，`η=0` 回归原式。误差界必须覆盖整拍，不可用当前观测误差替代未来界；`rbar` 也不能只界定命令速度。对任意前缀 `τ≤h` 用同一推导，以 `τ ε_W+τ²L_W/2` 构造功下界，减去线性耗散上界后为凹二次函数，起点与整拍端点的非负余量给出前缀非负。假设不成立时撤回认证并保留异常，不能下截断余额补能。

模块须保证上述实际速度界，而不只是接受一个名为 `rbar` 的输入：对 `d_j>0`，令 `q_j=(|P_c|η)_j`，先要求 `rbar_j−q_j≥0`，再将 `−(rbar_j−q_j)≤(P_cHy)_j≤rbar_j−q_j` 导出到同一外环；除非已有独立机械条件明确保证相同界。对 `d_j=0`，无需为该分量的耗散上界额外限速，已有机械限速不变。误差或停止保留额导致零命令也无能量可行性时，应报告能量/任务不可行，不能以发零伪造成功。

求解器只读预算快照，不能因“求过一个候选”就扣/充账。理想仿真可以使用已确认执行的保持速度；有延迟的 plant 必须使用实际速度或已声明整拍误差，不能直接标为 ideal。实际功以不重叠物理时间区间结算一次；接受命令只提交命令状态，不能立即使用本拍未来回能。拒发新命令不抹除旧命令的暴露。未知界的实机仅使用同一个 tank 的监测估计和误差日志，不另开可供能的“影子 tank”。

最低必要测试：

1. 完整六维净功相互抵消时不重复收费；只有扫描或计划姿态耗能时，`α` 确实被联合限制。物理 wrench 符号及参考点变换保持功率共轭。
2. 预算足够时，与**仅移除能量行、其余任务完全相同**的最优物理动作一致。预算不足但存在更小可行解时得到该解，不直接拒绝整个任务；零能量仍允许零功/回能的可行动作，受机械条件限制时如实报告。
3. 按最终 `|V|`、`|P_cV|` 重算扣账，不依赖可能不唯一的上图变量。只允许上限泄放，负余额保留并报失效。
4. `η=0`、非零误差、迟到/无效测量、拒发后旧命令持续、停止尾段以及重叠时间戳分别验证；错误、无穷或溢出的界不能产生额度。
5. 在显式理想执行和声明误差的数值例子中逐前缀检查能量不等式。未知硬件界只输出 UNVERIFIED；不得用测试全通过替代硬件界验证。

## 效果差：已确认机制与尚待验证的因果

### 终点实现缺陷污染了失败率

独立重读 840 条 metrics 和全部失败 NPZ：31 个 aborted 的最后普通扫描记录均为 `reference_s=3.0`，实测路径在 `0.05981294–0.05989768 m`，距 60 mm 终点仅 `0.102–0.187 mm`。其中 23 个记录 mechanical_infeasible，4 个反向/超进度，4 个离开 H；所有这些记录的实际机械越界事件为 0。15 条原始求解诊断仍有 MAX_ITER，必须保留。

代码的终点前馈从 0.02 m/s 跳成 0，以及上面的 H/加速度反例，强烈指向参考/收尾阶段冲突。另一独立源码诊断已对全部 8 个 full 中止重建数值：终点 H 允许的 Y 速度上界仅 `1.24–2.24 mm/s`，下一拍减速约束的下界为 `13.76–15.35 mm/s`，严格不交。其余变体的失败仍须分别保留数值状态，不能据此声称 31 个中止都只有同一个原因。该缺陷与患者接触不可修复不是同一结论。

### 全孔径的硬力恢复方向限制了修复能力

当前 v1 在 `c∈[−a,a]` 两端增加 `sign(F−F0)(Δvn−c Δω)≤0`。当 `F>F0` 且符号可靠时：

```
Δvn ≤ −a |Δω|
Δr(x) = Δvn − x Δω ≤ −(a−|x|)|Δω| ≤ 0， |x|<a
```

因此内部左右窗口均不能获得**相对同拍基线的新增压入**；想用 rocking 补压一侧时，公共退让至少抵消该侧的新增压入。当 `F<F0` 时反向得到 `Δvn≥a|Δω|`，两侧均不能得到新增卸载。基线自身仍可运动，真实图像也有其他变化来源，所以这不是“绝对不可能改善任何图像”的结论。

这是完整未知中心区间与逐拍硬方向条件的几何能力边界，增大图像权重无法绕过。只看投影到 `ω` 轴的可行区间会漏掉 `vn–ω` 的耦合锥；区间宽度几乎不变不代表 rocking 未受限制。现有 no_aperture 仍保留力方向行，image_only 又同时改变多个条件，二者不能单独识别这项约束的效果。

原附件主 QP 的有限孔径扰动预算与可选绝对力界，不等同于 v1 后来增加的逐拍全区间恢复方向硬条件。若尝试恢复原文的有界附加扰动折中，须作为**单独设计消融**：仅去掉力方向两行，其余 4 N 基线、孔径预算、进度代价、能量和机械保护相同；明确撤回对应局部零附加恶化保证。不能无根据缩小中心区间，更不能宣称它必然通过零裕量的端到端力验收。

### 持续坏图像没有退出无收益减速

shadow 的实际机械窗口始终良好，但独立 acoustic 和注册图像覆盖均为 0。Full 用时 7.45 s，baseline 3.26 s；力 RMSE 分别 0.12176 N、0.06098 N，未获得声学修复。保存的 full 普通扫描记录中，左右最低质量中位数约 0.111236，当前 `c_min=0.5` 给出 `alpha_preferred≈0.416855`，实际平均 α 为 0.416740，直接解释持续慢扫。

默认 full 的 consistency 本来关闭，不应悄悄打开来解释结果。即使启用，现有 gamma 仅作用于修复请求，不作用于减速代价；质量几乎不变时 consistency 还会因变化不足跳过更新。因此“启用 gamma”不等于实现了“记录缺口后继续”。

后续只需一个可选、局部、有上限的修复尝试消融：基于已经记录的实际局部动作与对时图像，在本位置额度耗尽或没有可用方向后停止额外修复和无收益减速，缺口继续计入损失，随后恢复原扫描偏好。它不判定组织物理不可修复，不训练 Jacobian，也不改变 required LEFT/RIGHT。不能每来一张相同坏图就重置额度。先独立验证，不默认启用，不与其他参数改动打包。

当前拟做的 bounded consistency 修正仍属于较窄的可选诊断：两幅图像 effective 时刻之间累计足够实测局部正向位移后，才检验正向/无/反向质量响应；最小观察时间和最小位移是显式设计参数。显著反向运动、无效图像、版本更换或测量间断须清除未完成证据，不能只累计正部而忽略中途卸载；图像采集之后、收到之前的动作不能用来解释该图。若只改 gamma 而不改 α，其验收也仅限修复请求，不得声称已修复持续慢扫。

### confidence 与真值余量、采集时钟限制了可见收益

healthy 的 full 扫描记录中，机械耦合良好比例为 100%，但左右最低 confidence 有 **12.59%** 的记录低于 0.5，形成不必要的修复/慢扫请求。这是阈值与合成图像特征尺度存在错配的证据；confidence 不是机械耦合概率，不能从数值 0.5 推断接触一半。应先检查原始特征在健康/缺口情况下的分布、窗口深度和阈值含义；带缺口场景必须将质量与**其有效采集时刻**的真值比较，不能拿约 0.152 s 延迟的质量对当前耦合算识别率。不得逐帧归一化抹去暗带来“修好”阈值。

另一独立诊断从冻结源调度推导实际消费图像年龄为 `160–195 ms`（不是已有日志直接记录的 age 字段）。限定“采集时该边窗确有声学缺口”之后，低分请求到达时该窗已恢复的比例仍为 left_gap `226/240=94.17%`、right_gap `252/288=87.50%`、delayed_execution `275/296=92.91%`。相应 baseline 缺口恢复中位时间仅 `145/185/170 ms`。这支持一个具体机制：短暂缺口大多已由基线自行恢复，外环才开始针对旧图修复；配准正确不等于旧缺口仍存在。先用已有动作历史做因果核查，不增加预测器或学习器来掩盖时延；零延迟仿真只能作为机制消融，不能当作现有硬件能力。

both_edges、curvature、moving_surface 的 baseline 已无机械缺失路径；它们可检验保持和力跟踪，但没有该缺失指标的改善余量。healthy 的注册图像间隔还留下采样端点缺口，图像联合覆盖与连续机械覆盖不可互换。shadow 则相反：机械覆盖完整而声学覆盖为零。已有独立真值须继续分列，不能把增加帧密度形成的端点变化解释为接触修复。

六个可修复场景的 full−baseline 缺失路径仅改善 **0.0211 mm**，有效覆盖速度下降 **0.1935 mm/s**；相对 matched_scan_speed，分别仅改善 **0.00495 mm** 和 **0.00151 mm/s**。这些是含失败记录的设计均值，没有显著收益或通过验收的含义。相同 exogenous 场并不意味着减速后经历相同时间扰动；应保留空间覆盖、真实耗时及匹配对照，不能只比较参考钟或无停止尾段的 RMSE。

## 本轮验收取舍
