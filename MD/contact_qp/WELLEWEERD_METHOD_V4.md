# Welleweerd 2020 方法对应关系

来源为用户提供的 `/home/camp/Downloads/Welleweerd2020automatic.pdf`，ICRA 2020，9946–9952 页，题名 *Automated robotic breast ultrasound acquisition using ultrasound feedback*。本轮按这篇论文选定方法，不增加训练模型。

## 复现什么

论文 II.C 使用 Karamalis 等 2012 的随机游走 confidence：上边界为 1，下边界为 0，图像强度、深度衰减和横向传播代价进入图权重。II.D 从 confidence 的浅层区域 P 提取均值和加权重心。实现保留真实概率值，显示固定 0–1 色标，不对最终 confidence 拉伸，也不把灰度黑区覆盖到 confidence 上。

使用的 B-mode 数值参考是共同作者 Tassilo Klein 公布的 [CAMP MATLAB 路径](https://github.com/TJKlein/Nakagami_Confidence_Maps)，其中 `confMap.m` / `attenuationWeighting.m` / `confidenceLaplacian.m` 是强度随机游走路径；没有使用该仓库的 Nakagami/RF 扩展。已有独立小图稠密 Laplacian 对照覆盖归一化、横向/斜向权重、上下边界与镜像。

论文只说缩放为 100 by 145，未指明宽高次序；当前显式选择高 100、宽 145。论文没有给出浅层 ROI 的数值边界、随机游走各参数、Cset 或二值缺失阈值。配置中的这些值均为实验初值，不宣称与作者未公开的配置完全相同。

论文式 (3) 的求和区域是 P，分母写作整幅图的 m×n；其文字又称浅层均值。为避免掩盖这个歧义，输出同时保留 `sum(P)/(m*n)` 和 `sum(P)/|P|`，控制窗口使用后者的 0–1 均值尺度。重心未做物理像素标定时只输出图像坐标，不生成假物理角度。

## 缺失区域输出的含义

按浅层逐列平均 confidence 和显式阈值划分低可信度区域，供用户查看声窗缺失估计。左右声窗均值仍进入联合 QP，中央只记录。阈值不是接触概率，无法仅凭它证明空气间隙或机械未贴合；骨性声影等也会降低 confidence。

无信号/无有效观测必须标为 unknown，不允许把随机游走在均匀图上的高浅层解当作良好贴合。unknown 的检查与 confidence 数值分别记录；不会伪造一幅看似检出成功的 confidence。已有真人离线图可检查实现和标注初值，真正修复方向、幅度和力精度仍由后续真实动作—图像配对实验判定。

## 与现有控制器的关系

这里只采用论文的图像特征方法。论文的立方误差 PD、绕探头端点转动和逐关节力矩能量罐没有替换用户冻结的设计：当前仍是 4 N 名义力控、原 TCP 转动基线、三变量外环 QP 输出六维速度、原内环 IK。

论文的 torque-level SAIP 无源证明不能直接移植到外环速度接口。当前能量证明必须从同一 TCP 六维端口的功、耗散和单一账本重新建立，并区分命令模型、实测估计和具有已验证误差界的物理认证。
