## QP 实际做了什么

扫描阶段 `h_ref_s>0` 共 6,153 拍：

- 新增法向速度最大绝对值仅 **0.000309 mm/s**；新增 rocking 最大绝对值仅 **0.000216 deg/s**。
- QP α 均值 **0.999756**，只有两拍降至 0.25。当时左右质量仍约 0.99，但图像有效年龄已超过 300 ms，属于旧图像过期策略；不是缺口修复驱动的持续减速。
- 最终模型参与保守参考进度授予，其因子均值 **0.974606**，与 QP α 不同，也不是实测速度。因此不能将 active 时长变化直接归因于声窗调速。
- 仍有原名义力控/力矩导纳产生的姿态运动；实测相对初始姿态 Y 分量约到 10.63°。这不等于 QP 新增了这么多 rocking。

寻触阶段另有 1,233 拍，其中 603 拍左右窗至少一个低于阈值；不能把“扫描阶段零低质量”推广到完整寻触过程。详细阶段计数与两次降速事件见 `command_phase_evidence.json`。

当前 active 图像整体更饱满，检测代理指标也更好，但开始时图像就已经与其他两次不同。加上重新示教、不同初始姿态，以及超声设备设置未完整独立记录，不能归因为新增 QP 修复。力 RMSE 比 baseline 小、比 shadow 大；一个非配对实验单元不足以通过原计划的零退化统计验收。当前能量功能未启用，此记录也不提供物理无源认证。
