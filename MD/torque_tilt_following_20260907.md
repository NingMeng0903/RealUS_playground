# In-plane 力矩随形中途停止

用户确认：沿面扫描仍继续，只有倾角不再修正。检查发现一处可独立复现该现象的姿态分支自锁；现有现场 CSV 没有倾角状态，不能把所有现场事件归因于同一原因。

原默认 `cop_stall_s=0.35`：压力中心 `|cop_x|>6 mm`，且 350 ms 内没有向中心缩小 1 mm，就锁存 `tilt_stalled` 并停止角速度。解锁又要求压力中心自行改善。软接触和持续曲面扫描并不保证压力中心在这么短的时间内单调回中，停止转动还会阻止改善。

在 4 N、旋转刚度 0.12 N·m/rad、目标倾角 0.5 rad 的理想弹性接触模型中，原逻辑在 0.39 s、1.44° 时锁存，最终停在 1.46°，残余力矩仍为 0.057 N·m；没有触发 QP 冻结或角度上限。关闭该启发式锁存后，10 秒内继续修正到 16.56°。数据见 [离线对照](torque_tilt_stall_20260907.json)。这些是模型结果，不是实机贴合精度。

已将 Python 配置默认值及 `force.yaml`、`controller.yaml` 的 CoP 停转启发式默认关闭。显式设置正数仍可启用旧机制，但现在反向力矩能够解除该锁存。接触门控、QP 残差冻结、150° 累计指令角度上限、速度和加速度约束保留。

**为什么关闭自锁后也可能尚未贴平就变慢/停止**

当前库仑死区为 `0.025 N·m`。在 `My=-x·Fz` 的 TCP 接触面模型下，4 N 时等效允许 6.25 mm 的压力中心偏移。对上面的旋转弹簧模型，死区允许约 11.9° 的静态角度误差；它保证的是小力矩平衡区，并非几何完全贴平。本次没有调整这个阈值，现有运行数据不足以把接触变化与补偿后静止力矩噪声可靠分开。

此外，`slack_norm>0.05` 会冻结倾角，但这是整个任务的总残差，不等于已确认某个关节碰到位置限位。丢失接触也会让倾角停下。当前配置关闭了世界姿态夹角冻结，累计角度限值为 150°；不能用它解释离线模型里只转 1.44° 就停止。

新 CSV 追加 `tilt_stop_reason` 和力矩、角速度、累计角度、CoP、接触/冻结/封顶/停转标志。原因值如下；它表示当前控制门控或死区状态，减速受加速度限制，门控出现时角速度未必已瞬间归零。

| 原因 | 含义 |
|---|---|
| 空值 | 没有上述门控，姿态分支在输出修正 |
| `torque_deadband` | 力矩误差进入库仑死区 |
| `no_contact` | 接触条件未满足 |
| `qp_slack` | 总任务残差触发冻结 |
| `angle_limit` | 继续沿同方向会越过累计角度上限 |
| `attitude_limit` | 显式启用的世界姿态角限制 |
| `cop_stall` | 显式启用旧 CoP 停转机制后触发 |
| `disabled` | 倾角支路关闭 |
