## 旧力约束为什么比“尽量恒力旋转”严格

当前探头半孔径 a=.025 m。F>4.1 N 时，旧约束要求相对名义的增量满足：

\[
\delta v_n\pm a\delta\omega\le0
\iff \delta v_n\le-a|\delta\omega|.
\]

所以整个孔径内 `δu(x)=δvn-x δω<=0`：不允许任何一侧相对名义新增压入。它允许边撤边转，却阻止通过“一边多压、另一边少压”重新分配接触。对于 ±.0155 m 的两个窗口，非零转动时二者的新增局部速度甚至都严格为负。1°/s 的额外旋转至少需要 .436 mm/s 的共同回撤，帮助缺失侧的新增压入方向因此被压掉。

这是为未知刚度分布采用的最坏情况约束，有保守依据，但不是保持总力所必需的唯一条件。之前将“旧条件不允许”表述成“任务没有修复能力”不准确。

在接触集合固定、局部线性且法向刚度分布 k(x) 有效的简化模型中：

\[
\dot F=K_0(v_n-c_k\omega),\quad
K_0=\int k(x)dx,\quad c_k=\frac{\int xk(x)dx}{K_0}.
\]

左右刚度对称时 c_k=0，小幅纯旋转一阶不改变总力；一般可以用少量法向补偿 `vn≈ck*omega` 控制合力。故“不必大幅增加力”的判断有依据。但零力矩只说明压力分布的一阶矩为零，不能推出刚度中心 c_k=0。力控有限带宽、接触边缘改变、黏弹性与执行延迟也使“自动保证力不偏离”不成立。4 N 与零力矩应是名义目标，不能同时作为转动期间严格不变的硬条件。

## 能量罐应该怎样参与

同一 tank 用来决定可允许的耗能程度是合理的。用已经扣除停止预留与未结算暴露的 Ea，可保持现有六维准入：

\[
\underline P(V)+\beta E_a/h\ge0,\qquad V=H[v_n,\omega,\alpha]^T.
\]

固定其他状态时，Ea增加会扩大能量许可集合，QP可更接近图像修复目标；Ea不足就限制净耗能动作。无需另造一个“激进修复tank”。图像目标决定是否值得修复，力软带和机械条件限制可接受动作，tank限制完整法向、转动、扫描等合成动作的能量。余额多不意味着必须加力，零余额也不必禁止回能/零功运动；不能提前花费预期未来回收的能量。

当前这一步没有在采集中启用。两份active配置 energy:null，六维ledger不建立。原名义TDPA配置为 enabled:true/apply:false，旧法向flow tank为observe；它们只是标量诊断，不提供对新rocking或α的六维能量准入。nominal_transaction还明确只允许这些旧可选层处于诊断模式。因此不能用“原控制器已有tank”代替新的联合能量约束。

tank即便启用，也不单独决定力峰值：简单弹簧就有 `F1²=F0²+2kΔE`，相同能量在不同刚度下对应不同力。4.5 N可以是修复允许带而非新的目标力；6 N测量监督不是未经建模的连续峰值证明。

## 对下一步实现的判断

应继续保留4 N名义目标，以带符号的confidence不平衡提出小幅差动修复，允许必要的少量法向补偿并惩罚无必要的共同加压；在同一QP内协调力矩偏好和图像目标，让α给修复时间，并把已有六维tank真正接入准入及结算。首先修正目标/约束分工与运行接线，不应把主要工作变成大幅加目标力或训练完整声学模型。

confidence用于in-plane姿态调整有直接先例：[Jiang等2020](https://hub.hku.hk/handle/10722/365383)；[力/图像混合控制的三种刚度仿体比较](https://research.utwente.nl/en/publications/comparison-between-force-andultrasound-image-based-controllers-fo/)也采用该思路。这些论文支持路线可行，不证明本项目当前参数或这五条记录的因果收益。能量tank的作用是约束额外控制行为的能量交换，可参见[Ferraguti等2013](https://iris.unimo.it/handle/11380/1012933)，其无源性结论同样依赖相应系统与端口假设。
